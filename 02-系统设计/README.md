# 系统设计

玩法与功能设计。三个版本各有用途：

| 版本 | 含义 | 权限 |
|------|------|------|
| [程序实现版本](./01-程序实现版本/) | 代码实际实现了什么 | 读写 |
| [本地设计版本](./02-本地设计版本/) ⭐ | 系统应怎么做（设计权威） | 读写；推送飞书 |
| [协作导入版本](./03-协作导入版本/) | 飞书协作拉取结果 | **只读**（会被覆盖） |

同步：`本地设计 → 飞书 → 协作导入`；采纳时再拷回本地设计。

## 程序实现版本（已有子系统）

核心循环 · 飞船 · 战斗 · 探索 · UI · 世界 —— 见 [01-程序实现版本/](./01-程序实现版本/)。

## 玩法速览

2D 物理飞船拼装与太空探索战斗：网格拼装模块；WASD/鼠标操作；视野+光照+雷达；机炮/护盾/钩爪；燃料与能源生存。

## 设计级别

总体设计（跨系统）→ 系统设计（单系统）→ 特性设计（功能点与验收）。
