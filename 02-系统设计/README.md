# 系统设计

本板块聚焦于 Spaceship 项目的**玩法与功能设计**，面向策划、程序、美术等多职能团队。

系统设计文档按三个**版本**组织，每个版本有独立的用途与同步策略。

---

## 版本总览

```
系统设计/
├── 📄 README.md                  ← 本文件
├── 📂 程序实现版本/               ← 从代码分析得出的当前实际实现
```

## 同步流程

```
本地设计版本 ──(推送)──► 飞书云文档 ──(拉取)──► 协作导入版本
     ▲                                              │
     │            阅读后如需采纳，复制到本地设计版本   │
     └──────────────────────────────────────────────┘
```

1. **本地设计**在「本地设计版本」中编写
2. 通过同步工具**推送到飞书云文档**
3. 外部协作者在飞书云文档上协作
4. 通过同步工具**拉取覆盖到「协作导入版本」**
5. 本地团队阅读协作导入版本，如需采纳 → 复制到本地设计版本

## 设计级别约定

| 级别 | 说明 | 文档要求 |
|------|------|----------|
| **总体设计** | 跨系统的宏观设计 | 系统全景图、核心循环、UI 框架 |
| **系统设计** | 单个系统的完整设计 | 玩法描述、交互流程、数值模型、配置表结构 |
| **特性设计** | 系统内的具体功能点 | 功能说明、边界条件、验收标准 |

## 核心玩法速览

> Spaceship 是一款 **2D 物理驱动的飞船拼装与太空探索战斗游戏**。

- **拼装**：在 1 米网格上自由组合 9 种模块，形成自定义飞船
- **操作**：W/S 进退、A/D 平移、Q/E 旋转、鼠标瞄准射击、F 交互
- **探索**：20m 基础视野 + 60°/80m 光照 + 100m 雷达，500m×500m 世界边界
- **战斗**：机炮弹丸、护盾反弹、钩爪拆解、尾焰持续伤害
- **生存**：燃料消耗、能源日结、模块损坏与修理
