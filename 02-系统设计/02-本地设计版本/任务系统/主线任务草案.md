## 1. 草案设计前提

| 前提 | 说明 |
|------|------|
| 玩家 | A 站驾驶员，被认为是克隆人的次等居民 |
| 站上势力 | 自由政府（独裁）、学社（技术官僚，相对独立）、共信会（金融/技术/宗教基金会） |
| 日常 | 驾驶智能载具出站，在环带废墟打捞回收物资，补给空间站 |
| 威胁 | 离散AI（环带大战遗留的战争兵器） |
| 目标类型 | 四类：摧毁敌舰 / 收集货物 / 到达目的地 / 存活天数（Q1 → D-9） |
| 完成模型 | 阶段模型：每阶段单目标，顺序推进（Q2/Q3 → D-10/D-11） |

## 2. 主线脉络（明线）

> 一句话：一个新驾驶员从出站打捞开始，替站上三股势力跑腿，逐渐在「捡垃圾」的日常中卷入站内暗流。

1. **序章·出站打捞**：成为驾驶员，完成首次出站作业，学会在废墟中生存。
2. **学社的委托**：学社需要一批特定物资，玩家替学社跑一趟。
3. **共信会的生意**：共信会开出不菲的报酬，请玩家回收一批指定残骸货物。
4. **政府的配额**：自由政府提高出站配额，玩家被迫承担更多作业任务。
5. **废墟中的信号**：玩家在作业中收到一段异常信号，指向一片未探索的残骸区。

## 4. 任务网络图

```
序章·出站打捞（起始，无前置）
 ├── 全部完成 → 学社的委托
 ├── 全部完成 → 共信会的生意
 ├── 任一完成（学社 或 共信会）→ 政府的配额
 └── 全部完成（政府的配额）→ 废墟中的信号
```

- **线性推进**：序章 → 学社/共信会 → 政府配额 → 信号
- **并行推进**：学社的委托 与 共信会的生意 可同时进行
- **分支/任一完成**：政府配额只需学社或共信会任一方完成即解锁

| 激活条件·无前置 | 3.1 | ✅ 够用 |

## 6. 草案验证点

| 验证点 | 通过条件 |
|--------|----------|
| 起始任务 | 序章无前置，系统初始化自动进入待接取 |
| 阶段推进 | 每个任务 2 阶段，阶段 1 达成后才显示阶段 2 |
| 并行推进 | 学社与共信会同时待接取/进行中，互不阻塞 |
| 任一完成 | 只完成学社或共信会其一，政府配额即解锁 |
| 全部完成 | 信号任务需政府配额完成才解锁 |
| 重复奖励防刷 | 完成过的任务状态入存档，重开不再可接取/领奖 |
| 金币发放 | 任务完成 → 货币管理器金币增加 → `CoinsChanged` 广播 |
