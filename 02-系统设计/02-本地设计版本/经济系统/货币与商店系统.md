# 货币与商店系统

> 草稿状态：评审中（待定稿）| 更新：2026-08-06（第二轮决策收敛）
>
> 本文档为**货币系统**与**商店系统**的设计草稿，内容由多轮决策收敛得出（grilling 会话 2026-08-06）。
> 标注「✅ 已确认」的条目已定稿；标注「⏳ 待确认」的条目仍待决策，见 §6 问题清单。
>
> 本文档与《[车间编辑器与仓库（物理拼装版）](../飞船系统/车间编辑器与仓库（物理拼装版）.md)》配套：仓库是商店的操作对象，商店绑定空间站，空间站绑定指定仓库。冲突条目以本文档为准。

## 1. 系统全景

Spaceship 的经济闭环围绕「探索带回报 → 回港交易 → 补给与升级」展开：

> **出航打捞（模块 / 货物 / 宝藏）→ 结算进入仓库 → 回港在商店出售换金币 → 用金币购买补给与模块 → 再出航**

本设计包含两个系统：

| 系统 | 一句话定位 | 边界 |
|------|-----------|------|
| **货币系统** | 管理玩家永久金币：存储、增减、查询 | 纯数据层，不参与任何业务逻辑 |
| **商店系统** | 出售补给与模块、收购玩家从仓库带来的物品 | 交易编排，绑定空间站与指定仓库 |

三者关系：

> 货币管理器是「钱包」，仓库是「货舱」，商店是「交易窗口」。商店在空间站内营业，买卖双方分别是玩家仓库与商店货架，结算货币走货币管理器。

## 2. 货币系统

### 2.1 系统描述

管理玩家的永久货币。金币通过主动出售模块、货物（含宝藏）以及完成任务赚取；「完成任务」的金币来源见《[任务系统](../任务系统/任务系统.md)》（决策 C-10）。货币管理器独立于游戏管理器，不随飞船损毁而丢失。

### 2.2 货币管理器（对象）

玩家永久持有货币的唯一归属，由独立的货币管理器负责存储、增减与查询。货币管理器**只负责金币的存储、增减和查询，不参与任何业务逻辑**（不判断买卖合法性、不计算价格）。

### 2.3 数据

| 数据 | 类型 | 说明 |
|------|------|------|
| 金币数量 | 整数 | 初始值为 0 |
| 欠账（兜底） | 整数 | 初始值为 0；资金不足时自动垫付的差额累计值。当前实现**可无限累计（暂无累计上限）、不会为负**；欠账的额度机制（偿还途径、是否封顶等）仍在设计中，本版只做累计、不参与消费结算 |

### 2.4 状态与行为

| 行为 | 规则 |
|------|------|
| 金币增加 | 接收外部系统的增加指令，将指定数量金币加入当前余额 |
| 金币扣除 | 接收外部系统的扣除指令。余额足够 → 扣除并返回成功；余额不足 → 不执行任何操作并返回失败 |
| 欠账记账 | 接收外部系统的垫付指令，将指定金额累加至欠账（余额不变）；用于「资金不足自动垫付」的兜底路径（失败罚金差额、最低供给借贷补全，见 §3.4、§3.5 S-20） |
| 余额查询 | 提供只读查询接口：当前金币数量与当前欠账，供 UI 与各系统调用 |

### 2.5 事件

| 事件 | 触发时机 | 载荷关键字段 |
|------|----------|--------------|
| `CoinsChanged` ✅ | 金币数量变化后 | 变化量、新余额 |

> ✅ **决策 C-7**：货币变更走事件广播（`readonly struct` 载荷），UI / HUD / 商店订阅刷新；货币管理器不引用任何订阅者，遵循事件-订阅规范。

### 2.6 已确认决策

| # | 决策 | 内容 |
|---|------|------|
| C-1 | 货币独立于游戏管理器 | 金币存储于独立货币管理器，不随飞船损毁或单局结束丢失；跨局、跨会话持久化至存档 |
| C-7 | 货币变更走事件 | `CoinsChanged` 事件广播（见 §2.5） |
| C-10 | 任务来源 | 系统描述中的「完成任务赚取金币」由任务系统发放给货币管理器（见《[任务系统](../任务系统/任务系统.md)》）；货币变更走 `CoinsChanged` 事件（决策 C-7） |

## 3. 商店系统

### 3.1 系统描述

商店不仅出售出航所需的基础物资，也收购玩家从环带中带回的模块和货物。

### 3.2 商店（对象）

出售能源、燃料、弹药及基础模块，同时允许玩家向其出售任意模块和货物以换取金币。

### 3.3 数据

| 数据 | 说明 |
|------|------|
| 商品配置表 | 策划配置的商品列表，每项包含商品类型、具体物品 ID、购买价格、单次刷新最大库存量；程序读取此表生成商店界面 |
| 基准价 | 每个物品/模块定义资产上的「基准价」字段 |
| 收购折扣率 | 收购价 = 基准价 × 稀有度折扣率；普通 50% / 稀有 60% / 史诗 70% |
| 刷新间隔 | 默认 1 个游戏日，可配置 |
| 绑定仓库 | 商店绑定空间站，空间站绑定指定仓库；购买与出售的操作对象均为该指定仓库 |
| 赎回池 | 玩家卖出物品后进入的独立临时列表，与货架库存分离；商店提供单独赎回页面，可按出售价买回（见 §3.4 回购） |
| 最低供给配置 | 独立配置资产（`MinimumSupplyConfig`）：食物 / 燃料 / 弹药的最低供给目标量，默认食物 5、燃料 5、弹药 0（0 表示不强制）；低于目标视为需要借贷补全（见 §3.4、§3.5 S-20） |

### 3.4 状态与行为

| 行为 | 规则 |
|------|------|
| 购买 | 玩家选择商品与数量。金币足够 → 扣金币，商品存入绑定仓库；金币不足 → 拒绝购买；仓库放不下 → 拒绝购买并提示整理（见决策 S-6、S-10） |
| 出售 | 玩家从绑定仓库选择物品。按基准价 × 折扣率计算并显示出售价；确认后移除物品、增加金币，物品**进入赎回池**而非货架（见决策 S-9） |
| 回购（赎回） | 商店提供单独赎回页面。本次交易结束前，玩家可按**当时实际出售价**购回赎回池中任意物品，落点回到绑定仓库（见决策 S-11、S-12） |
| 借贷补全（最低供给） | 车间初始化时检查「仓库 + 编辑区船体」的各类资源总量，低于最低供给目标量时解锁拼装界面出航下方的「借贷补全物资」按钮；点击后**不检查金币**、直接按商店价从货架赊账购买缺口（消耗货架库存、存入绑定仓库），全部费用累计至欠账。测试模式不检查、不提供（见决策 S-20） |
| 交易结束清理 | 离开休整站（出航）即交易结束：赎回池清空，未赎回物品不再可回购（见决策 S-5） |
| 库存刷新 | 出航瞬间检查「距上次刷新是否经过 N 个游戏日」，到了则刷新货架库存；刷新时赎回池同时清空（见决策 S-5、S-13） |

### 3.5 已确认决策

| # | 决策 | 内容 |
|---|------|------|
| S-1 | 商店可卖模块 | 推翻旧定稿「模块不开放金币购买」；基础模块双向可买卖 |
| S-2 | 珍稀模块扩展 | 后续珍稀模块可能在商店禁售、仅地图获取；框架需支持「按物品/模块配置买卖能力」（预留点见 Q23） |
| S-3 | 参数可配置 | 价格、折扣率、库存、刷新等均 SO / 表驱动，开发者可配置，不硬编码 |
| S-4 | 商店位置 | 框架上下文无关、可挂任意状态；默认仅挂拼装状态（休整站）。探索中可能出现商店（见 §6 Q26，原文分支保留，规则待定） |
| S-5 | 交易边界与刷新 | 刷新按累计游戏内天数（默认 1，可配置）；刷新发生在**出航瞬间**；交易结束 = 离开休整站（出航），此时赎回池清空、货架刷新。反复开关商店不清空赎回池 |
| S-6 | 购买落点 | 购买内容存入商店绑定空间站所指的指定仓库；不直接上船、不进旧版 moduleInventory/cargoInventory |
| S-7 | 出售来源 | 只从绑定仓库出售；不直接卖编辑区飞船上的模块（需先收回到仓库再卖） |
| S-8 | 独立货架库存池 | 商品表「单次刷新最大库存量」即商店独立货架库存，与仓库分离；玩家买走即减，刷新时按规则重置（见决策 S-13） |
| S-9 | 卖出进赎回池 | 玩家卖出物品**不进入货架**，单独进入商店赎回池；商店有独立赎回页面 |
| S-10 | 购买仓库放不下 | 拒绝购买并提示「仓库空间不足，请整理后再购买」，金币不扣；不做半自动腾空间流程 |
| S-11 | 回购价格锁定 | 回购价 = 玩家当时实际出售价（当时基准价 × 当时折扣率），不受后续刷新/折扣变化影响 |
| S-12 | 回购落点 | 回购回到绑定仓库（与购买同落点）；仓库放不下则拒绝回购并提示 |
| S-13 | 刷新重置满量 | 刷新后货架库存重置为配置的最大库存量（确定性），不做随机浮动 |
| S-14 | 商店存档 | 只存「上次刷新累计游戏天数」+ 各货架剩余库存；赎回池不存档（出航即清空） |
| S-15 | 欠账不耦合 | 欠账不影响商店消费；**普通商店购买只检查当前金币**。欠账的额度机制（偿还、上限等）仍在设计中，本版欠账仅作为兜底累计 |
| S-16 | 模块买卖朝向 | 卖出：在堆叠格上选「卖一个」即卖该格 (类别, 朝向) 组合；买入：进模块页对应堆叠格（朝向由商店配置指定或默认 Forward）；不做「模块个体挑选朝向」粒度 |
| S-17 | 休整站商店入口 | 拼装界面增加「商店」按钮，打开商店覆盖层界面；不在场景里做独立商店交互物 |
| S-18 | 测试模式商店 | 商店正常可用，货架视为无限库存（或按配置），金币照常增减（是否无限金币由开发者开关） |
| S-19 | 珍稀模块预留点 | 在模块/物品定义资产上配置 `CanBuy` / `CanSell` 标记（默认 `true`）+ 稀有度字段；购买列表过滤 `CanBuy=false`，可售列表过滤 `CanSell=false`。珍稀模块 = 表内 `CanBuy=false` 即可禁售，地图掉落机制另起设计 |
| S-20 | 最低供给借贷补全 | 车间初始化时检查「仓库 + 编辑区船体」的资源总量（`MinimumSupplyConfig` 配置目标量）；低于目标解锁出航下方「借贷补全物资」按钮，点击后从货架按商店价赊账补齐缺口、费用全部计入欠账。是商店消费中**唯一绕过金币检查**的路径（见 §2.3、§2.4 欠账记账）。测试模式不检查、不提供 |
| P-1 | 基准价位置 | `CargoItemDefinition` 与 `ModuleDefinition` 各配「基准价」字段；商品表「购买价格」仅用于货架定价 |
| P-2 | 购买价与基准价 | 默认购买价 = 基准价，商品表内可覆盖（促销/溢价） |
| P-3 | 模块稀有度 | **模块新增稀有度字段**（普通/稀有/史诗），当前实装模块全部为普通稀有度；与货物共用同一折扣率表 |
| P-4 | 宝藏买卖 | 商店出售物品页全部内容（含宝藏）；宝藏手动出售入口就在商店；结算页只展示价值、不自动出售 |

### 3.6 与仓库 / 空间站的关系

```
空间站（撤离点）
  └── 绑定指定仓库（WarehouseDefinition）
        ├── 模块页 / 物品页 / 船体页
        └── 商店买卖的操作对象 = 此仓库
货币管理器（金币） ⇄ 商店（买卖结算）
商店内部：货架库存池（独立于仓库） + 赎回池（玩家卖出物品）
```

- 商店不感知编辑区物理结构（`WorkshopEditorSpace` / 结构拖动等），只对接「仓库 + 货币管理器」两个服务
- 出售 = 从仓库移除物品 → 货币管理器增加金币；购买 = 货币管理器扣金币 → 物品进仓库

## 4. 价格模型

### 4.1 价格来源

| 价格 | 计算 |
|------|------|
| 购买价 | 商品表「购买价格」，默认 = 定义资产基准价，表内可覆盖 |
| 出售价（收购价） | 定义资产基准价 × 稀有度折扣率（普通 50% / 稀有 60% / 史诗 70%） |

> ✅ **决策 P-1、P-2**：基准价挂定义资产（`CargoItemDefinition` / `ModuleDefinition`），保证「任意物品可卖」都能算出收购价，与货架无关。

### 4.2 稀有度与折扣率

折扣率表为「稀有度 → 折扣率」的公共映射，货物与模块共用：

| 稀有度 | 折扣率 |
|--------|--------|
| 普通 | 50% |
| 稀有 | 60% |
| 史诗 | 70% |

> ✅ **决策 P-3**：模块新增稀有度字段（当前实装模块全部为普通），与货物共用该表。折扣率数值为可配置默认值。

## 5. 事件契约

| 事件 | 触发时机 | 载荷关键字段 | 状态 |
|------|----------|--------------|------|
| `CoinsChanged` | 金币数量变化 | 变化量、新余额 | ✅ 已确认 |
| `ShopTransactionCompleted` | 一次买卖成功 | 物品、数量、金额、类型（买入/卖出/回购） | ⏳ 待确认 |
| `ShopStockRefreshed` | 货架刷新 | 刷新后货架状态 | ⏳ 待确认 |

> 借贷补全（决策 S-20）也广播 `ShopTransactionCompleted`（类型为买入），欠账记账经 `CoinsChanged` 载荷中的欠账字段同步给 UI / HUD。

## 7. 与旧文档的差异

| 旧表述 | 现状 |
|--------|------|
| 金币存储于游戏管理器 | 金币由独立货币管理器管理（本设计） |
| 商店出售「部分基础模块」 | 商店可卖全部基础模块，双向可买卖（决策 S-1） |
| 「在外出探索时，若飞船没有储存格子，提示腾出空间」 | **保留原文分支**——探索中可能出现商店（决策 S-4，用户确认保留）；探索中商店的具体规则后续另议 |
| 「若出售的模块正安装在当前飞船上，提示确认」 | 出售只从仓库取货，此分支废弃（决策 S-7） |
| 模块不开放金币购买 | 基础模块开放购买，珍稀模块按配置禁售（决策 S-1、S-2） |
| 结算自动换算宝藏为金币 | 宝藏进物品页，手动在商店出售；结算页只展示价值（决策 P-4） |
| 回购列表 = 卖出物品进货架 | 卖出物品进独立**赎回池**，商店有单独赎回页面（决策 S-9） |
