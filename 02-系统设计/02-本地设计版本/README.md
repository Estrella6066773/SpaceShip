# 本地设计版本

本目录是系统设计的**本地编写与维护版本**，是设计文档的「主本」。

- **同步方向**：本地 → 飞书云文档（**单向同步**，以本地为准，推送到云端）
- **权限**：读写。可在此目录自由创建、修改、删除文档
- **角色**：设计权威源。策划与程序的协作产出均在此处落笔
- **受众**：策划、程序、美术等全职能

---

## 同步说明

本目录将由专门的同步工具单向推送到飞书云文档：

```
本地设计版本 ──(推送)──► 飞书云文档
```

- 本地修改后，运行同步工具即可将内容更新到云端
- 云端修改**不会**反向同步回本目录
- 如需参照他人从协作导入版本传入的内容，请查看 [协作导入版本](../03-协作导入版本/)
