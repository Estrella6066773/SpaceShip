# 车间编辑器与仓库（物理拼装版）——特性设计

> 本地设计主本 | 状态：设计中（物理版已实现，特性验收中） | 更新：2026-08-06
>
> 本文档定义新版车间编辑界面：**物理化拼装**、**自由格仓库**、**船体蓝图**。三者为同一套系统：仓库是零件与物品的局外存储，车间编辑页是把仓库资源拼成飞船的工作台，船体蓝图是拼装结果的可保存形态。
>
> 本文档取代旧版车间编辑器（网格拼装）与旧版「飞船蓝图」玩家侧功能的交互定义；旧版相关文档（《飞船蓝图与车间模块仓库》《拼装与模块》等）中与此冲突的条目以本文档为准。
>
> 规格来源：策划口述设计 + 多轮决策收敛（决策记录见 §12）。

---

## 1. 概述

### 1.1 系统定位

| 系统 | 一句话定位 | 发生时机 |
|------|-----------|----------|
| **自由格仓库** | 「我有哪些零件与物品」——模块、物品、船体的局外存储，随存档跨局保留 | 常驻 |
| **车间编辑器** | 「怎么拼这艘船」——从仓库取出模块与物品，物理化拼出飞船 | 两次出航之间的整备阶段 |
| **船体蓝图** | 「我拼好的船存下来」——编辑区结构的可保存形态，供下次拖出复用 | 车间内随时 |

### 1.2 设计目标

- 车间编辑从「网格放置」升级为「积木式物理拼装」：保留模块的太空物理效果与相邻自动链接能力，拼装过程本身成为玩法
- 仓库统一承载模块、物品（燃料/能源/弹药/宝藏）、船体三类资源，用自由格背包模型表达，容量与堆叠上限均可配置
- 仓库不与撤离点绑死：任意绑定，可多撤离点共享一个仓库，也可各自独立
- 编辑期保持「编辑场景 + 仓库总量不变」的零和语义，杜绝复制刷资源；**出航是唯一扣减点**
- 「船体」继承并取代旧版蓝图功能，作为玩家的拼装收藏与快速铺装手段

### 1.3 与旧版的关键差异

| 维度 | 旧版（程序实现版本） | 新版（本文档） |
|------|---------------------|----------------|
| 拼装方式 | 1m 网格 + 四向朝向放置 | 物理自由坐标，模块如积木 |
| 旋转 | R 键 90° 增量切换朝向 | R 键持续施加角加速度（扭矩），松开靠角阻尼自然减速（SO 可调） |
| 模块库存 | `(类别, 朝向) → 数量` 聚合列表 | 自由格仓库，单格堆叠（上限 SO 配置） |
| 货物库存 | 类别级聚合列表 | 物品页自由格，含 23 个具体宝藏物品 |
| 玩家飞船存档 | `ShipBlueprint` 资产（仅内容侧） | 船体蓝图（玩家侧存入存档）+ 内容侧 SO 蓝图双轨 |
| 出航校验 | 至少一核心 + 全船连通 + 至少一种物资 | 恰好一核心 + 船上能源/燃料达最低需求 |
| 出航组成 | 全部模块上船 | 核心连通组上船，零散部件整组回收 |
| 宝藏经济 | 结算自动换算金币 | 全部进物品页，金币仅手动出售获得（出售功能后续开发） |

## 2. 界面结构

车间编辑器分为左侧仓库区与右侧编辑区：

```
┌───────────────┬──────────────────────────────────┐
│   仓库（左）   │         编辑区（右）               │
│               │                                  │
│  页签：        │  模式随页签联动：                 │
│  模块 / 物品   │  模块/船体页 → 模块模式            │
│  船体         │  物品页 → 物品模式                 │
│               │                                  │
│  （可折叠）    │   物理空间（含模块、物品、边界墙）  │
│               │                                  │
└───────────────┴──────────────────────────────────┘
```

### 2.1 左侧仓库

仓库有 **3 个页面**，通过页签切换：

| 页面 | 内容 | 承载对象 |
|------|------|----------|
| **模块** | 模块堆叠格 | 各类模块（按单格堆叠） |
| **物品** | 物品堆叠格 | 能源 / 燃料 / 弹药 / 宝藏（按单格堆叠） |
| **船体** | 船体蓝图格 | 已保存的船体蓝图（成船或非成船） |

### 2.2 右侧编辑区

编辑区有 **2 种模式**，**随仓库页签切换**：

| 模式 | 对应页签 | 操作对象 | 说明 |
|------|----------|----------|------|
| **模块** | 模块页 / 船体页 | 模块（含模块组成的结构） | 物理拼装、拖动、链接 |
| **物品** | 物品页 | 物品（燃料/能源/弹药/宝藏） | 拖动物品、拾取/放下、装入储存模块 |

模式联动规则：

- 切换到「模块」页签 → 编辑区进入模块模式，操作对象是模块，物品不可编辑、不参与拖动
- 切换到「物品」页签 → 编辑区进入物品模式，操作对象是物品，模块不可编辑、不可能达成将其拖动的行为
- 切换到「船体」页签 → 编辑区保持模块模式（船体是模块组成的结构，船体保存与拖出都发生在模块操作语境）
- 编辑区不再设置独立的模式切换按钮：模式完全由仓库页签决定

## 3. 仓库（自由格背包）

### 3.1 结构

仓库是一种存储结构，包含两类内容：

1. **模块**：按 `(模块类别, 朝向)` 聚合为条目，一格一个条目，单格堆叠上限可配置
2. **物品**：能源 / 燃料 / 弹药 / 宝藏，**按具体物品定义**堆叠（同一具体物品定义才合并，与储存模块货物规则一致），单格堆叠上限可配置
3. **船体**：船体蓝图条目（见 §3.3）

逻辑仿照**单格存在堆叠上限的自由格背包**：

- 仓库有**总格数**（SO 配置）
- 每个模块堆叠格与物品堆叠格各有**堆叠上限**（SO 配置）
- 放入时自动寻找可合并格（同类、同具体定义、未达上限）→ 找不到则占用空格 → 格满则无法放入（见 §11 边界）
- 船体蓝图每个占用一格，不参与堆叠

### 3.2 SO 配置（仓库定义）

仓库的容量与堆叠规则通过 ScriptableObject 独立配置，**每个仓库实例一份配置**：

| 字段 | 说明 |
|------|------|
| 仓库名称 | 显示名 |
| 总格数 | 自由格数量上限 |
| 模块堆叠上限表 | 按模块类别配置单格堆叠上限（如动力模块 10、储存模块 5） |
| 物品堆叠上限表 | 按物品类别配置单格堆叠上限（如燃料 10、宝藏 1） |
| 绑定撤离点列表 | 该仓库绑定的撤离点（可为空，由运行时绑定） |

### 3.3 绑定关系

仓库**不与撤离点绑死**，支持任意绑定：

- 地图的全部撤离点可以绑定**同一个**仓库（共享库存）
- 每个撤离点可以配置**独立**仓库（各自库存）
- 绑定关系由撤离点侧引用仓库实例决定；多撤离点引用同一仓库 = 共享

> 默认（未特殊配置时）：所有撤离点共享一个默认仓库。撤离点如何进入仓库界面（绑定入口交互）属 UI 层扩展，不在本文档范围内。

### 3.4 存档

仓库内容为局外资源，随存档跨局、跨会话保留：

```
SaveData
├── warehouses[]: WarehouseSave[]      ← 新增字段（新存档直接落盘）
│   ├── 仓库定义引用（GUID）
│   ├── 格列表：模块堆叠格 / 物品堆叠格 / 船体蓝图格
│   └── （绑定关系由撤离点场景引用或存档字段维护）
└── （原 moduleInventory / cargoInventory 字段废弃，见 §12 决策 24）
```

> **迁移策略（已确认）**：当前无既有存档玩家，**不做旧存档迁移**。新存档从新结构直接落盘，旧 `moduleInventory` / `cargoInventory` 字段废弃，不承担兼容负担（见 §12 决策记录）。

## 4. 物理编辑交互

### 4.1 基础物理

- 编辑区是带物理的空间：模块有刚体、质量与碰撞，**整体模拟太空环境**——低摩擦、低阻尼、保留失重与动量
- 模块 **相邻自动链接**：任意模块在这里都有发起「合规链接」的能力
- 旋转：选中模块按 R 键**持续施加角加速度（扭矩）**，按住期间持续加速；松开后靠角阻尼自然减速，不设瞬转、不设档位（参数 SO 可调）
- 拖动即施力：按下结构/物品拖动且未抬起时，对刚体施加真实弹簧-阻尼力，物体获得加速度与动量，可碰撞、可保留动量滑行（见 §4.2）

### 4.2 拖动整体结构

- 左键**按下某个模块** → 开始拖动
- 拖动时，**该模块与它链接的整个结构**一起移动（链接组作为一个整体）
- **锚定相对坐标**：按下时记录指针与结构质心/锚点的相对偏移，拖动中结构尝试归位到相对锚定的位置（弹簧式跟随）
- **弹簧施力**：拖动（未抬起）时对刚体持续施加弹簧-阻尼力（按质量归一化，大小结构手感一致）；物体因此获得加速度与动量，可撞击、可携带动量
- 拖动过程中：
  - 结构受物理拖拽效果影响，弹簧与阻尼参数 SO 可调
  - 结构**可以撞到其他块**（物理碰撞生效）
  - **禁止在拖动中与路过模块建立新链接**（防粘连，见 §4.3）
- 松手后：保留拖动获得的动量自然滑行减速；按 §4.3 的接触面贴合判定尝试链接；无链接目标则停留在物理静止位置

### 4.3 链接

- **合规链接**：两模块的接触面满足「面法线对向、角度误差在阈值内、间距在阈值内」时自动建立链接（阈值 SO 可调）；建立后**锁定相对变换**，成为同一结构
- **拖动期间禁止建立新链接**：被拖结构移动途中经过的模块只产生物理碰撞，不粘连；松手（或进入仓库区抬起）后按接触面贴合统一判定
- 链接成立后，该链接组视为整体，继续受 §4.2 拖动规则约束

### 4.4 抬起与落下

拖动物品与模块时，存在**抬起 / 落下**两个状态：

| 状态 | 物理 | 链接 | 触发方式 |
|------|------|------|----------|
| **抬起** | 无物理（不参与碰撞） | 不可发生链接 | 进入仓库区；或鼠标达到「高速」标准 |
| **落下** | 有物理 | 可自行链接 | 抬起后速度不足 / 未达高速时保持落下 |

规则：

- **从仓库拖出的模块/物品/船体，初始即为抬起（非下落）状态**：随鼠标移动，不参与物理、不建立链接
- 鼠标**进入仓库区** → 抓起对象（抬起），使其不再接收物理碰撞
- 鼠标**速度达到「高速」标准** → 拿起对象（抬起）
- 鼠标速度不够快时 → 对象保持**落下**状态，拥有物理效果，且可以与其他对象产生物理效果并发生链接
- **拖出**（离开仓库区）直到**松手**，才解除抬起状态
- 拿起后状态**保持**：一旦抬起，即使速度降至阈值以下也维持抬起，直到松手

### 4.5 编辑区边界

- 场景右侧（及四周）存在**碰撞箱**，阻止对象被抛出编辑区边界
- 对象被边界墙挡回，不丢失、不销毁

## 5. 收起与拖出

> **「收起」只在模块与船体模式（页签）被选中时生效**：物品模式下操作对象是物品而非模块，此时不可编辑模块，也不可能达成将其拖动的行为。

### 5.1 模块页收起

- 将**模块（或模块组成的结构）拖入仓库区**，触发「收起」
- 收起 = **将模块拆散成模块**，放置到模块页的堆叠格中（按堆叠规则合并/占格）
- 收起后编辑区该结构消失
- **储存模块的货物**：收起储存模块时，其内部货物转入物品页对应堆叠格

### 5.2 船体页收起

- 船体是一种模块组成的结构，**根据是否存在核心**区分为「成船」与「非成船」（成船判定规则后续可能调整，但概念已敲定）：
  - **成船**：结构包含核心模块（场上恰好一个核心为出航硬性前提，见 §7.2）
  - **非成船**：结构不含核心
- 将结构拖入仓库区（船体页被选中）时：
  1. **保存此蓝图为船体**（无论成船 / 非成船均可保存）
  2. **当前结构归位**：按移动逻辑自动拖回目标点（回到拖出前的位置），不拆散
- 船体页中的每个条目 = 一个可复用的船体蓝图

### 5.3 船体页拖出

- 从船体页**按住船体蓝图拖出**（非按钮点击）：按下蓝图即进入拖出状态，结构跟随鼠标
- 拖出时**自动消耗仓库组件生成结构**：
  - 需要仓库中持有该蓝图所需的全部模块与（蓝图内配置的）物品
  - **物资不足时**：缺失的物品和模块**显示为红色**，且不消耗仓库资源
  - 在**仓库页面内松开**（未拖出仓库区）→ **解散结构**、退还物资（回到仓库格）
  - **拖出松手后**：缺失部分**不会落地**（不会以缺失状态生成到编辑区）
- 整个拖出过程中，**编辑场景和仓库中持有资源的总量不会变化**（零和）

## 6. 物品模式

- 右侧编辑区切到「物品」模式时，操作对象为物品
- 拖动物品同样遵循 §4.4 抬起/落下：落下时物品可被拖入**邻近储存模块的空槽**完成装入（装填交互）
- 物品与模块的「链接」一词仅用于模块；物品的放入语义为「装入储存模块槽位」
- 装入规则沿用储存模块规则：4 格 × 每格同类 ≤10；同具体定义才合并

## 7. 出航与试飞

### 7.1 组成规则

玩家执行「出航」或「试飞」时：

1. 以**核心模块**为起点，沿链接遍历，得到**核心连通组**
2. 与核心连通组链接的模块 = **船体部分**，随玩家出航
3. 其他不链接的部分 = **零散部件**，**整组回收到仓库**（按模块页堆叠规则入格）

### 7.2 出航校验（现场校验，未通过不切换状态）

| 校验项 | 规则 | 提示（示例） |
|--------|------|--------------|
| 核心数量 | 场上**恰好一个**核心模块；无核心 / 多核心均禁止出航 | 「飞船必须且只能包含一个核心模块」 |
| 物资需求 | 船上装载的 **能源 ≥ 最低需求 且 燃料 ≥ 最低需求**（最低需求 SO 可调，当前默认 5）；弹药不强制 | 「能源不足，无法出航（最低 5）」 |
| 船体合法性 | 核心连通组内部模块通过有效链接连通 | 「模块之间存在断裂」 |

校验通过后生成出航快照（含零散部件回收结果），进入出航探索场景。

### 7.3 试飞

- 试飞与出航共用 §7.1 组成规则与 §7.2 校验
- 试飞语义（副本 or 真实结构、试飞中模块摧毁/消耗是否算数）见 §11 待确认项，默认建议：试飞为**真实结构**，试飞中消耗与摧毁与出航一致（尚未定稿）

## 8. 结算与失败

### 8.1 结算

- 结算页**保留**，展示本次出航的物品清单与价值（价值表查询展示），但**不自动出售**
- 金币**仅手动出售**获得：物品页后续增加出售功能（本版本先做展示，出售功能后续开发）
- 出航带回的宝藏**进入物品页**（仓库存量），不自动换算

### 8.2 失败

- 失败时：**仅销毁本次上船模块**（核心连通组）
- 已回收的零散部件与仓库内资源**保留**
- 已知取舍：不设最小出航配置门槛，玩家理论上可「只带核心裸奔出航」规避失败资源损失；该取舍可接受，后续版本可迭代为配置门槛或仓库扣罚（记录见 §12）

## 9. 数据模型

### 9.1 运行期与存档

```
ShipRuntimeSnapshot / 出航快照（改造：网格坐标 → 连续坐标）
├── 模块项：Kind, Facing, 本地坐标(Vector2), 旋转(角度), MaxHealth, 状态
└── 物品槽位：按格快照

WarehouseSave（存档新增）
├── 仓库定义引用（GUID）
├── ModuleStack[]：格位 + (Kind, Facing) + 数量
├── ItemStack[]：格位 + 具体物品定义 + 数量
└── HullSlot[]：格位 + 船体蓝图数据

HullBlueprint（玩家船体库，存存档）
├── 名称
├── 模块布局：模块定义 + 连续坐标 + 旋转
└── 货物配置：蓝图内储存模块的物品配置
```

### 9.2 内容侧（资产）

| 资产 | 用途 |
|------|------|
| `WarehouseDefinition` SO | 仓库容量 / 堆叠上限 / 绑定（§3.2） |
| 内容侧 `ShipBlueprint` SO | 预配置初始飞船、敌舰、残骸生成（沿用旧机制，与玩家船体双轨并存） |
| `HullDefinition`（可选） | 可收藏的官方船体（内容侧），与玩家自定义船体同构 |

## 10. 事件框架

新增车间事件源（`WorkshopEventSource`，挂载车间场景，遵循事件-订阅规范）：

| 事件 | 载荷关键字段 | 广播时机 |
|------|--------------|----------|
| `StructureChanged` | 结构引用、变更类型 | 链接建立/断开、结构拖动落定 |
| `ModuleCollected` | 模块 (Kind, Facing)、数量 | 模块页收起成功 |
| `HullSaved` | 船体名称、成船/非成船 | 船体页收起保存成功 |
| `HullSpawned` | 船体名称、缺失清单 | 船体页拖出生成结构 |
| `DepartureCompositionResolved` | 上船模块数、回收模块数 | 出航/试飞组成解析完成 |
| `WarehouseContentChanged` | 仓库引用、变更格数 | 仓库任意增减 |
| `ItemSold` | 物品定义、数量、金币 | 手动出售（后续版本） |

> 载荷一律 `readonly struct`；事件源不引用订阅者；UI / Audio / FX 订阅响应。

## 11. 边界与异常

| 场景 | 行为 |
|------|------|
| 仓库格满 / 堆叠满 | 先尝试合并可合并格，再尝试空格；仍放不下则**拒绝放入并提示**，资源不凭空消失 |
| 零散部件回收时仓库放不下 | 优先自动开新格；格满则拒绝该次出航（或提示整理后再出航，二选一由程序定） |
| 船体拖出物资不足 | 缺失项红显；仓库内松手解散退还；拖出松手后缺失部分不落地 |
| 收起储存模块 | 模块入模块页，内部货物入物品页对应堆叠 |
| 拖动中结构撞块 | 物理碰撞生效，不粘连（拖动期间禁链接） |
| 对象被拖出边界 | 碰撞墙挡回，不丢失 |
| 拿起后速度下降 | 保持抬起，直到松手 |
| 首次游戏 | 仓库预置初始零件 + 船体页预置初始船体（成船），直接可用 |
| 失败返回 | 仓库资源保留，船体页恢复失败前的船体库 |
| 测试模式 | 使用**真实仓库 + 预加载不限数量伪存档**（全部模块类别与物品各一格，数量显示 ∞，非旁路背包），放置/收起不写存档 |
| 非成船船体出航 | 允许保存、允许拖出编辑，但出航时场上必须恰好一个核心（玩家自行补核心） |

## 12. 已确认决策记录（2026-08-05 / 08-06 收敛）

| # | 决策 | 要点 |
|---|------|------|
| 1 | 完全物理化 | 彻底去网格；位置自由连续，模块如积木操作 |
| 2 | 旋转物理化 | 按 R 持续施加角加速度（扭矩），松开靠角阻尼自然减速；对象是模拟太空环境的刚体（低摩擦、低阻尼、保留动量） |
| 3 | 仓库 = 自由格背包 | 总格数、单格堆叠上限均 SO 独立配置 |
| 4 | 仓库任意绑定 | 撤离点绑仓库，多对一或独立皆可 |
| 5 | 拖动 = 移动整体结构 | 锚定相对坐标、弹簧归位、可撞块、拖动中禁止粘连 |
| 6 | 抬起 / 落下双态 | 高速或进仓库区 → 抬起（无物理、不可链接）；否则落下（有物理、可链接）；松手才解除 |
| 7 | 模块页收起 | 整结构拆散成模块入模块页 |
| 8 | 船体页收起 / 拖出 | 拖入保存船体蓝图并归位；拖出消耗仓库组件生成结构，缺失项红色、仓库内松手解散退还、不落地 |
| 9 | 非成船可存船体 | 无核心结构也能保存为船体蓝图（零件布局收藏） |
| 10 | 出航组成规则 | 核心连通组视为船体上船，零散部件整组回收进仓库 |
| 11 | 出航硬校验 | 场上恰好一个核心；船上装载能源 ≥ 5 且 燃料 ≥ 5（SO 可调） |
| 12 | 宝藏经济 | 全部宝藏进物品页；金币仅手动出售获得 |
| 13 | 结算口径 | 结算页展示本次物品清单及价值，不自动出售，出售功能后续开发 |
| 14 | 失败处置 | 仅销毁本次上船模块（核心连通组）；已回收零散部件与仓库资源保留 |
| 15 | 零和编辑 | 编辑场景 + 仓库总量不变；出航是唯一扣减点 |
| 16 | 编辑区模式随页签联动 | 仓库页签切换决定编辑区模式：模块/船体页 → 模块模式，物品页 → 物品模式；编辑区不设独立模式按钮 |
| 17 | 按住拖出 | 模块、物品、船体蓝图的拖出均为「按住拖出」（按下即拖、非按钮点击） |
| 18 | 从仓库拖出初始抬起 | 从仓库拖出的对象初始为抬起（非下落）状态，随鼠标移动，不参与物理与链接 |
| 19 | 拖动施力与动量 | 拖动（未抬起）对刚体施加真实弹簧-阻尼力，物体获得动量；松手保留动量滑行减速，不瞬停 |
| 20 | 链接与拿起阈值 | 链接判定区恢复精确尺寸（面贴合判定）；拿起「高速」阈值调低（更灵敏） |
| 21 | 测试模式伪存档 | 使用真实仓库 + 预加载不限数量伪存档（全模块类别与物品各一格、数量显示 ∞，非旁路背包）；放置/收起不写存档 |
| 22 | 默认存档预置物资 | 首次游戏仓库预置初始零件，船体页预置初始船体（成船），开箱可测 |
| 23 | 施力/加速度检测 | 编辑区实时显示当前施加给拖动对象的力 / 加速度 / 角加速度，供玩家与调试确认物理施力确实生效 |
| 24 | 旧存档不迁移 | 当前无既有存档玩家，不做旧 `moduleInventory` / `cargoInventory` 迁移；新存档从新结构直接落盘 |

**已知取舍**：决策 14 不设最小出航配置门槛，存在「只带核心裸奔出航」规避失败损失的可能，本版本接受；后续版本可迭代为最小配置门槛或失败仓库扣罚。

**待程序确认项**：

- 试飞语义：副本 or 真实结构；试飞中模块摧毁/消耗是否算数（建议真实结构、与出航一致）
- 零散部件回收时仓库格满：拒绝出航 or 提示整理（建议提示整理）
- 编辑区尺寸与模块数量上限（性能；建议 SO 配置 + 刚体数量上限）
- 链接阈值具体数值（面法线对向角度误差、间距、吸附容差；判定区已恢复精确尺寸，具体初值建议 SO 可调）
- ~~旧存档 `moduleInventory` / `cargoInventory` 的迁移落格规则~~ 已确认：当前无既有存档玩家，旧存档兼容可不做；新存档直接从新结构落盘，不承担迁移负担

## 14. 验收标准

1. 仓库按自由格背包呈现：总格数、单格堆叠上限来自仓库定义 SO，同条目自动合并、格满拒绝并提示；模块/物品以格子型展示，支持按住拖出
2. 仓库三页（模块/物品/船体）切换正确，编辑区模式随页签联动（模块/船体页 → 模块模式，物品页 → 物品模式）；编辑区无独立模式按钮，物品模式下模块不可拖动
3. 左键按住模块可拖动其链接整体；结构受物理拖拽、可撞块、不粘连；松手后按接触面贴合判定链接
4. 按 R 对选中模块/整体持续施加角加速度（扭矩），按住持续加速、松开靠角阻尼自然减速；对象为模拟太空环境的刚体（低摩擦、保留动量）
5. 鼠标进入仓库区或达到高速 → 对象抬起（无物理、不可链接）；速度不足保持落下（有物理、可链接）；松手解除抬起；从仓库拖出的对象初始即为抬起状态
6. 模块页收起：结构拆散成模块入堆叠格，储存模块货物转入物品页
7. 船体页收起：保存为船体蓝图、结构归位；成船/非成船均可保存
8. 船体页按住拖出：消耗仓库组件生成结构；物资不足缺失项红显且不消耗；仓库内松手解散退还、不落地；过程中编辑场景与仓库总量不变
9. 出航：核心连通组上船、零散部件整组回收；无核心/多核心拒绝出航；能源/燃料低于最低需求拒绝出航
10. 结算页展示物品清单与价值、不自动出售；失败仅销毁上船模块，仓库资源保留
11. 编辑区实时显示当前施加给拖动对象的力 / 加速度 / 角加速度；未拖动或抬起时归零，不残留上一次检测值
12. 测试模式：仓库预加载不限数量伪存档（全模块类别与物品各一格、数量显示 ∞，非旁路背包），放置/收起不写存档；首次游戏默认存档含预置初始零件与初始船体
