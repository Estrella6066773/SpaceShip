# 协作导入版本

本目录是从**飞书云文档单向导入**的设计文档副本，由外部协作者在云端编写后同步到此。

- **同步方向**：飞书云文档 → 本地（**单向导入**，以云端为准，覆盖本地）
- **权限**：只读。**请勿在此目录直接编辑文件**——所有修改都会被下次导入覆盖
- **角色**：外部协作输入源。供本地团队阅览外部人员提交的设计内容
- **受众**：全体开发者（只读参考）

---

## 同步说明

本目录将由专门的同步工具从飞书云文档单向拉取：

```
飞书云文档 ──(拉取/覆盖)──► 协作导入版本
```

- 同步工具运行后，本目录内容将被云端**完全覆盖**
- 如需引用外部设计内容，请将相关文档复制到 [本地设计版本](../02-本地设计版本/) 后再修改
- 如需向外部反馈设计意见，请在飞书云文档上直接标注或评论

## 重要提醒

> ⚠️ **本目录下所有文件会被同步工具覆盖。如果在此处编辑了文件，修改将在下次同步时丢失。**
>
> 正确的协作流程：
> 1. 阅读此处的外部设计内容
> 2. 如需采纳或修改 → 复制到 [本地设计版本](../02-本地设计版本/)
> 3. 在本地设计版本中修改并推送至飞书云文档
