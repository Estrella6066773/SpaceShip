# 飞船系统 — 程序实现版本

> 基于 `d:\Unity\Spaceship` 代码分析 | 更新：2026-07-29

---

## 模块化拼装

飞船由多个独立 `ShipModule` 在 **1 米网格** 上自由组合。核心组件：

| 组件 | 类 | 职责 |
|------|-----|------|
| 飞船总成 | `ShipAssembly` | 模块管理、质量/质心计算、摧毁逻辑、阵营判断 |
| 模块 | `ShipModule` | 网格坐标、四向链接、生命值/精灵、碰撞体 |
| 交互 | `ShipAssemblyInteractionController` | 链接/拆卸交互、碰撞检测、引导线反馈 |
| 安装器 | `ShipPrefabRuntimeInstaller` | 从蓝图 SO 实例化飞船 |

**代码位置**：`Assets/Scripts/Gameplay/Ships/Assembly/`

---

## 9 种模块类型（ModuleKind 枚举）

定义在 `ModuleDefinition` ScriptableObject 中：

| 枚举值 | 中文名 | 实时功能 |
|--------|--------|----------|
| `Core` | 核心模块 | 被摧毁 → 整船坠毁 |
| `Thruster` | 动力模块 | Forward/Right/Back/Left 四向推力，位置决定力矩（杠杆原理） |
| `Radar` | 寻敌雷达 | 100m 扫描，右键短按开关，可配置扫描目标阵营 |
| `Light` | 发散光束 | 60°×80m 照明，右键短按开关，单射线遮挡检测 |
| `Cannon` | 固定式机炮 | 左键开火，消耗弹药，有冷却时间 |
| `Grapple` | 拆卸钩爪 | 右键长按 2s 拆卸非核心模块，可携带并重新安装 |
| `Shield` | 电磁盾 | Forward/Right 双面护盾，吸收伤害，反弹弹丸与雷达 |
| `Storage` | 储存模块 | 4 个货物槽位（能源/燃料/弹药/宝物），每槽同类 ≤10 |
| `Empty` | 基础模块 | 只有质量与生命，无主动功能 |

## 物理模型

- **运动**：`ShipMotionController` + `Rigidbody2D` + Input System
  - 总推力 = Σ(动力模块推力系数) × 全局推力参数
  - 力矩 = Σ(推力 × 到质心垂直距离)，核心推力作用于质心
  - 超载惩罚：模块数 > `LoadCapacity` → 推力衰减
- **质量**：所有未摧毁模块质量之和（`ShipAssembly.TotalMass`）
- **质心**：模块位置加权平均（`ShipAssembly.CenterOfMass`）
- **碰撞反馈**：`ShipCollisionFeedback` 产生摄像机震动

## 链接系统

- 相邻模块自动链接（链接碰撞体检测）
- 已链接 → 锁定碰撞对；分离 → 取消并重新检测
- 近期拆除模块 → 60 秒内更短链接时长
- 四向锚点视图（`ModuleLinkAnchorView`）
- 候选锚点脉冲 + 世界空间进度条（`ShipLinkFeedbackPresenter`）

## 货物系统

| 组件 | 功能 |
|------|------|
| `ShipCargoHold` | 槽位管理、跨仓转移、拖出抛弃 |
| `CargoPickup` | 世界空间货物拾取 |
| `CargoConsumptionService` | 定时消耗燃料/能源/弹药 |
| `CargoRevealCoordinator` | 货物鉴定流程（Unidentified → Identified） |

### 储存模块格子配置（2026-08-04 新增）

| 组件 | 功能 |
|------|------|
| `CargoSlotConfiguration` | 单格配置：`Fixed`（指定货物）或 `WeightedRandom`（权重随机）二选一 |
| `WeightedCargoCandidate` | 随机候选：货物 + 数量 + 权重（任意正数，不要求归一化） |
| `StorageModuleCargoConfiguration` | 挂在储存模块对象上，固定 4 格（2×2），关卡加载时按种子一次性结算 |

实现要点：

- 每格配置独立，支持同一模块内混用指定 / 随机模式
- 随机只在初始化时结算一次（`resolved` 标志），此后格内为确定性货物
- 玩家船填充为已鉴定；非玩家单位 / 残骸为未鉴定，进入揭示流程
- 模块被击毁时 `DestroyModule` → `RemoveStorageContents` 一并销毁货物；拆除 / 断裂 / 残骸打捞时货物随模块保留
- 编辑器校验器（`CargoConfigurationValidator`）检查候选池合法性，重复候选给出警告
- **现状**：新机制已落地——四类货物定义（食物/燃料/弹药/宝藏）与 `Assets/Prefabs/Modules/储存模块.prefab` 上的混合格子配置（随机 + 指定）已就位，工坊拼装路径生效。随机候选池中的宝藏已**细化为 23 个具体物品**（普通 11 / 稀有 6 / 史诗 6，含收编的「失落星核」），类别级「宝藏」仅保留给旧蓝图机制；现有 Blueprint 飞船的内联储存模块仍走旧的 `ShipInitialCargoPlacement`，与新格子配置按设计并存

## 资源消耗

| 组件 | 消耗规则 |
|------|----------|
| `ShipFuelConsumptionManager` | 每 100 米结算：核心 2 + 存活动力 ×1 燃料，不足即坠毁 |
| `ShipFoodConsumptionManager` | 每日定额消耗（默认 5 能源），不足即坠毁 |
| `ShipAmmunitionConsumptionManager` | 按开火次数消耗，弹药不足拒射并广播不足事件 |

统一语义（不足才死、未鉴定不可消耗、只作用于玩家船）见 **[消耗管理器规格](./消耗管理器规格.md)**。
