# 拆卸钩爪 · 半自动确认制 · 实现需求（v2.1）

- 日期：2026-08-20（v2.1 修订：并入评审决议）
- 状态：实现需求草案（未立项）
- 范围：键鼠操作；**本版不含手柄支持**（项目未实装手柄输入）
- 对照基线：现状全自动 `ShipGrappleController`（`ShipGrappleController.cs`）
- v2 变更：拆卸读条改为钩爪伸缩动画（5s）；冷却默认 0（可配置）；丢弃无冷却；新增"抓取核心→损毁"处决技；携带物可被摧毁；钩爪被摧毁时携带物变残骸；抓取/安装直接清灰
- v2.1 修订（评审并入）：① 输入仲裁改为**指针优先**（自己船语义无条件优先于钩爪候选）；② 侧翼弹开改为**按连通性分组**（B、C 不互相链接即各自独立残骸）；③ 安装目标改为**链接边绿/红提示**（绿=可安装实际落点）；④ 接触判定明确为**黄金矿工式**（伸出→接触→夹紧→缩回）；⑤ case 2 弹开方向修正为**沿锁链线背离玩家**；另修正冷却 Min 约束、B-10 / B-2 / 丢弃名册登记等实现提示与处决技事实表述

---

## 1. 概述

钩爪是特殊武器类模块，从"全自动拆装"改为"**半自动确认制**"：系统自动检测合法目标并高亮提示，**玩家按键确认后才执行**。玩家表达 = 靠近 + 确认；系统负责检测、锁定与结算。

**动作形式**：拆卸与安装采用**钩爪伸缩动画**（黄金矿工式：伸出 → 接触判定 → 夹紧 → 缩回），总时长 5 秒，取代原读条；动画全程未接触目标模块 = 未拿到。

## 3. 状态机

冷却为**叠加屏蔽标志，不单独成状态**：冷却中（若配置 >0）检测与高亮照常，仅确认被屏蔽并提示。

```
Idle（冷却中为叠加标志：检测/高亮照常，确认无效，提示"冷却中 x.xs"，丢弃不受屏蔽）
 ├─ 检测到合法目标 → Waiting（高亮候选 + 提示"右键确认 拆卸/抓取/安装"）
 │     ├─ 右键短按（指针不落自己船模块）→ 动作中（Detaching / Installing / ExecutingCore）
 │     │     · 拆/装：伸缩动画 5s（伸出→接触→夹紧→缩回），全程未接触=失败
 │     │     · 抓取：即时完成
 │     │     · 抓核心：5s 读条 → 核心损毁
 │     ├─ 候选失效 → 回 Idle，提示"目标已失效"
 │     └─ 无操作 → 保持 Waiting（候选随移动实时更新，切换最短驻留 0.2s）
 ├─ Carrying（携带中）
 │     ├─ 检测到敌船可安装链接点（绿边）→ Waiting → 确认 → Installing
 │     ├─ 无安装目标 → 提示"敌船无空闲链接点"，可丢弃
 │     └─ 右键长按 2s → Dropping → 变自由残骸（无冷却；释放后登记回场景名册）
 └─ 动作完成（若配置冷却）→ 冷却屏蔽计时，计时结束恢复确认
```

| 状态 | 进入条件 | 离开条件 | 反馈 |
|---|---|---|---|
| Idle | 无候选 / 动作完成 | 出现候选 → Waiting | 无 |
| Waiting | 检测到候选 | 确认 / 候选失效 | 高亮（0.2s 驻留）+ 提示文本 |
| Detaching | 确认拆卸 | 接触 → 携带；全程未接触 → 失败 | 伸缩动画 5s |
| Grabbing | 确认抓取 | 即时完成 | 抓取动画 + 清灰 |
| ExecutingCore | 确认抓取核心 | 5s 读条结束 → 核心损毁 | "正在摧毁核心 x.x/5.0s" |
| Installing | 确认安装 | 动画完成 / 取消 | 伸缩动画 5s |
| Carrying | 抓取/拆卸完成 | 安装完成 / 丢弃 / 被摧毁 | HUD 状态"抓取中" |
| Dropping | 右键长按 2s | 即时完成 | "已释放" |

## 4. 行为流程

### 4.1 检测（每帧）
- 前提：飞船可操作、存在存活钩爪模块。**冷却中（若配置）检测与高亮照常，仅确认被屏蔽**（见 4.8）。
- 空手：射程 + 锥形内，优先级 敌模块 ＞ 残骸；过滤玩家船核心、已摧毁模块。**敌人核心不在此过滤内**（可被识别为抓取目标，见 4.5）。
- 携带：仅检测敌船可安装链接点（3m 射程，不查锥形；见 4.6 绿/红边）。
- 命中 → Waiting，高亮候选并提示动作文案；候选切换最短驻留 0.2s，防高亮跳变。

### 4.2 确认（右键短按）—— 指针优先
- 分派顺序（同一帧按下，写死判定顺序）：
  1. **自己船语义无条件优先**：指针悬停自己船模块（非核心）→ 现状语义（短按开关 / 长按拆下）；**即使锥形内存在外部候选也先执行自己船语义**；
  2. **外部钩爪候选**：否则当前存在 Waiting 候选 → 确认钩爪动作；
  3. 否则无操作。
- 确认瞬间锁定目标（动作针对锁定目标，不随"最近"实时重选）。
- 确认对象 = 锥形内最近候选，**指针不参与候选选择**。可选增强（默认不启用）：指针下的合法外部模块优先成为候选，更贴合"指针优先"直觉。
- 实现影响：需在 `ShipAssemblyInteractionController.TickModuleRightClick` 与 `ShipGrappleController` 之间增加右键仲裁——指针落在自己船模块上的判定先行，其余在钩爪存在候选时由钩爪消费。

### 4.3 拆卸（伸缩动画 5s，取代读条；黄金矿工式）
- 确认后锁定目标 M，播放"伸出 → 缩回"动画，共 5s。
- **伸出**：钩爪从钩爪模块伸出，**最长 = 射程（默认 3m，可配）**；伸出方向**朝向锁定目标**（确认时已保证目标在 30° 锥内，故目标在钩爪伸出方向可达；若坚持沿钩爪模块正前直线伸出，需注明锥形边缘目标不可达）。
- **接触判定**：钩爪前端与目标模块碰撞体相交（或前端-目标中心距离 ≤ 接触阈值）→ **夹紧**该模块，随后**缩回**（夹紧后即视为已拿到，不再因距离/锥形取消）。
- **失败**：全程（伸出+缩回）前端从未到达目标 → "未接触到模块"，无模块被拆下（目标提前脱离/被毁/超出射程均自然失败）。
- 接触成功结算：
  - **拉脱分组**：M 被拉脱，同时 **M 与全部邻接模块的链接断开（拉脱瞬间撕断）**；所有与剩余船体（核心连通组）断开的模块**按相互连通性分组**，每组生成一个**独立残骸刚体**；**M 单独被携带**（计入质量与质心）。
  - **弹开方向**（以 M 原位置为原点，作正交于锁链方向的直线 L）：
    - 各组残骸位于 L 一侧、互不连通 → 各自**沿 L 向背离缺口方向**弹开（B 向左、C 向右），初速度 2 m/s；
    - B、C **同一连通组**（经 M 背后路径相连、横跨 M 两侧）→ 整组**沿锁链线、背离玩家方向**弹开（修正方向①：与主模块被拉走方向相反）；M 在敌船近表面时该方向指向敌船内部，预期表现为残骸撞上残余船体停下/弹开（物理自解），验证需确认不穿模；
    - M 背后沿 d 的其余断连组（如咽喉模块后的前段）→ 与横跨组同向（沿锁链线背离玩家）。
- 完成 → 进入冷却（默认 0）。
- 实现影响：现状 `DetachModule` + `CollectDetachedGroup`（`ShipAssembly.cs`）**有意**把 M 与所有断连模块焊成一个残骸刚体（注释明说"而不是被后续的断开分组拆成多个残骸"），与本规则正面冲突——需改为"逐连通组生成残骸刚体"（可复用 `SplitDisconnectedGroups` 思路，把 M 排除在外）。附带变化：携带物从 v1 的"整组"变为"仅 M"，质量/质心增量变轻；若希望 M 拽走背后整串（含 X），需另定义"沿 d 的附属链随 M 携带"，当前版本按 M 单独携带。

### 4.4 抓取残骸（即时）
- 确认 → 立即抓取，播放抓取动画，残骸**直接清灰**（现状拆卸产物已无灰，需补的是抓取脏残骸即时清灰），计入质量 → 进入冷却（默认 0）。

### 4.5 处决技：抓取敌人核心（读条 5s）
- 空手时，检测目标若为**敌人飞船核心模块** → 提示"右键确认 摧毁核心"。
- 确认 → 钩爪抓住核心，**读条 5s**（状态 ExecutingCore）。
- 读条结束 → **核心模块被损毁**，走现有核心损毁路径，事实为：
  - `DestroyModule(core)` → `ApplyCoreExplosion`：**仅对敌船自身 3×3 邻格施加 `CoreExplosionDamage`** → `MarkDestroyed`（状态层"全船摧毁"：清零速度并广播 `ShipDestroyedEvent`，**船体模块仍留在场景**）；
  - "掉落残骸"只发生在 3×3 波及区（邻格被毁 → `SplitDisconnectedGroups` 产出残骸）；
  - **爆炸天然不伤玩家**（只作用于敌船自身网格），B-17 现状即满足，无需额外免疫代码。
- 读条中目标脱出射程 / 敌船被摧毁 → 取消并提示。
- **可达性预期**：3m 射程够不到深埋核心的大船 → 处决技实际只对核心外露或小船可用（若希望任意船可处决，需另行提高射程或定义穿透规则，本版不做）。

### 4.6 安装（伸缩动画 5s；链接边绿/红提示）
- 携带中检测：取射程内最近敌船，以携带模块为锚枚举其各模块链接点，判定"方向双向兼容（`IsLinkEnabledInAssemblyDirection`）+ 目标格空闲" → **可安装**。
- **呈现**：候选链接边 **绿色 = 可安装（即实际安装落点，所见即所得）**；**红色 = 不可安装**（方向不匹配 / 目标格被占等）；无任何绿边 → 提示"敌船无空闲链接点"（B-13），仅可丢弃。取代 v2.0"敌船整船边框 + 遍历第一个空闲格"的黑盒方案。
- 确认 → 伸缩动画 5s（黄金矿工式契约同 4.3）。
- 动画中目标船被摧毁 / 链接点被占 → 取消并提示。
- 完成 → 模块装上敌船 → 进入冷却（默认 0）。
- 实现：绿/红边枚举可直接复用 `TryFindInstallGrid`（`ShipAssembly.cs`）的方向兼容 + 空闲检查；绿/红边绘制为新增 Presenter 工作。

### 4.7 丢弃（右键长按 2s）
- 携带中右键长按 2s → 释放为自由残骸，**无冷却，随时可用**（不受冷却屏蔽）。
- **实现前置**：现状 `Grab()` 已 `UnregisterShip`，但 `ReleaseCarriedAssembly`（`ShipAssembly.cs`）**不把残骸登记回场景名册** → 释放后需补 `ShipSceneRegistry.SynchronizeShip`（必要时补 `Initialize`），否则丢弃物不在 `SalvageShips`，既不能"靠近自动链接"打捞（B-9）也不能被再次抓取。
- 丢弃残骸进入场景名册后，可被"靠近自动链接"打捞（见边界 B-9）。
- 待拍板：携带 + 有安装候选时，同键长按 2s=丢弃 / 短按释放=确认安装存在歧义——按到约 1.9s 松手会误触 5s 安装动画（且动画不可取消）。建议丢弃用**独立键（如 G）**，或长按期间显示丢弃进度、松手可取消；若坚持同键需接受"短按释放即确认安装"。

### 4.8 打断与反馈
- 动作取消一律给出原因文本（"目标脱离射程" / "目标已失效" / "未接触到模块" / "安装目标消失"）。
- 冷却中（若配置）检测到候选 → 提示"冷却中 x.xs"，确认无效（高亮照常）。

## 5. 输入与反馈（键鼠）

| 输入 | 指针指向外部目标 | 指针指向自己船 |
|---|---|---|
| 右键短按 | 确认钩爪动作（拆/抓/装/处决核心） | 开关模块（现状，**无条件优先于钩爪候选**） |
| 右键长按 2s | 携带时：丢弃 | 拆下自己船模块（现状） |

- **仲裁规则**：指针悬停自己船模块时，无论锥形内是否存在外部候选，一律执行现状语义（见 4.2 / B-12）；"外部优先"仅在指针不落自己船模块时成立。
- 候选高亮：`ShipModuleActivityPresenter` 橙色连线体系，**切换最短驻留 0.2s**（现状仅在动作中画钩爪线，需扩展 Waiting 状态候选线）；
- 安装目标高亮：**链接边绿/红**（绿=可安装实际落点；红=方向不匹配/格被占），无绿边 → "敌船无空闲链接点"；
- 动作反馈：钩爪伸缩动画、抓取动画、处决读条进度文本、状态文本；音效/特效留待美术接入。

## 6. 边界条件表

| # | 条件 | 行为 | 状态 |
|---|---|---|---|
| B-1 | 飞船失能（无核心） | 清空钩爪状态，不检测 | 明确 |
| B-2 | 钩爪模块被摧毁 | 钩爪模块消失；**携带物直接变自由残骸**；不检测不执行。**实现前置：现状仅 `ResetAction`，需新增"携带物变自由残骸"逻辑** | 明确 |
| B-3 | 冷却中（若配置 >0） | 检测与高亮仍工作，确认无效，提示冷却；**丢弃不受冷却屏蔽** | 明确 |
| B-4 | 动作中目标脱出锥形（仍在射程） | 不取消（接触判定只看前端可达性）；夹紧后不再因距离/锥形取消 | 明确 |
| B-5 | 动作中目标脱出射程 | 拆卸：夹紧前脱离 → 全程未接触 → 失败；其他：取消 + 提示 | 明确 |
| B-6 | 确认瞬间候选已失效 | 提示"目标已失效"，不执行 | 明确 |
| B-7 | 拆卸动画中目标模块被摧毁 | 夹紧前被毁 → 未拿到，无模块被拆下 | 明确 |
| B-8 | 安装动画中目标船被摧毁 / 链接点被占 | 取消 + 提示 | 明确 |
| B-9 | 丢弃后残骸靠近自己船 | 自动链接可能立刻吸回（接受：等于"把模块还给船"）；需先登记回场景名册（见 4.7） | 明确 |
| B-10 | 携带物被攻击 | **可被摧毁**；被摧毁时模块与**货物一并销毁**（不掉落）。**实现前置：现状 `DestroyModule` 只认 `modules`，`carriedModules` 打空血不销毁（`ShipModule.ApplyDamage` → `ShipAssembly.DestroyModule`），需新增携带物伤害/销毁路径** | 明确 |
| B-11 | 多个钩爪模块 | 取第一个存活钩爪 | 明确 |
| B-12 | 指针同时覆盖自己船与外部目标 | **自己船语义无条件优先**（即使锥形内有候选）；"外部优先"仅当指针不落自己船模块（4.2 写死） | 明确 |

## 8. 验证要点

- 重写 `AllModuleFunctionValidator.TestGrapple`：检测→高亮→确认（**指针仲裁：指针在自己船 + 锥形有候选 → 现状语义生效**）→拆卸（**黄金矿工式接触判定**）→**连通性分组弹开**（独立组 / 横跨组 / 背后组）→携带（仅 M，质量计入）→安装（**绿/红边**）→丢弃（**名册登记后可再抓取**）→处决核心→冷却（配置时，含 Min(0) 放开）
- 手动验证场景：指针在自己船上 + 锥形有候选时现状语义可用；动画未接触失败（目标脱离/被毁）；夹紧后脱离射程仍拿到；弹开方向（独立组 / 横跨组 / 咽喉组，横跨组背离玩家且不穿模）；丢弃与自动链接交互；处决核心爆炸（玩家免疫、3×3 掉落残骸、深埋核心不可处决）；携带物被摧毁（含货物销毁）；冷却配置（默认 0、配置 >0 时屏蔽与丢弃例外）
