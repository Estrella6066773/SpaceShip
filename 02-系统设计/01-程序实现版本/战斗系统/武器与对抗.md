## 武器系统

### ShipCombatController

| 流程 | 说明 |
|------|------|
| 输入 → 开火 | Input System 左键 → 检查冷却 → 检查弹药（`ShipAmmunitionConsumptionManager`） → 生成 `Projectile2D` |
| 冷却 | 每个机炮模块独立冷却计时 |
| 弹体 | `Projectile2D`：直线飞行、碰撞检测、命中伤害、自毁 |
| 尾焰伤害 | 动力模块尾焰对附近敌舰持续伤害 |

### 已实现武器

| 类型 | ModuleKind | 弹体 | 冷却 | 弹药 |
|------|-----------|------|------|------|
| 固定式机炮 | `Cannon` | `Projectile2D` | 有 | 消耗弹药（CargoType.Ammunition） |

## 钩爪系统

### ShipGrappleController

| 操作 | 行为 |
|------|------|
| 激活 | 右键长按非核心模块，持续锁定 2 秒 |
| 拆卸 | 2 秒后目标模块从 ShipAssembly 分离 |
| 携带 | 被拆模块跟随钩爪，计入总质量 |
| 安装 | 对准空闲链接面 → 重新链接 |
| 限制 | **不可拆卸核心模块** |

## 伤害规则

| 规则 | 说明 |
|------|------|
| 敌我判定 | 玩家子弹伤敌、敌人子弹伤玩家，友军伤害默认关闭 |
| 伤害公式 | 基础伤害 ×（1 + 质量修正）- 护盾吸收 |
| 摧毁判定 | 核心被毁 → 全船摧毁；所有动力被毁 → 全船摧毁 |

## 敌舰 AI

`EnemyShipController` 实现三状态巡逻/追踪 AI：

```
Patrol（巡航路径点移动，定时雷达扫描）
  └─ 发现目标 → Tracking
Tracking（追踪玩家，自动开火）
  └─ 目标丢失 → Patrol   |   被摧毁 → Destroyed
```
