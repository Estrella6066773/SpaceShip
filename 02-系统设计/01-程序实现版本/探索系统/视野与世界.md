## 系统拆分

探索相关逻辑分布在多个模块中，协作关系如下：

- **玩法感知模块**（`Spaceship.Gameplay`）：视野/雷达数据计算
- **视野渲染模块**（`Spaceship.Vision`）：视野画面渲染（URP RenderFeature）
- **世界模块**（`Spaceship.Gameplay.World`）：世界生成、小行星、残骸

模块间通过数据桥接（`PlayerShipVisionPolygonBridge`）与事件通信协作。

## 视野系统

### 数据层（感知层）

`SpaceshipVisibilityController`（`Assets/Scripts/Gameplay/World/`）：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 基础视野半径 | 20m | 所有飞船恒定拥有 |
| 雷达扫描范围 | 100m | 需安装雷达模块并激活 |
| 照明角度 | 60° | 发散光束扇面角 |
| 照明范围 | 80m | 发散光束有效距离 |
| 雷达过期时间 | 可配置 | 扫描结果超时标记无效 |

**遮挡规则**：
- 小行星遮挡雷达（物理射线检测）
- 照明视野多边形：只有地形（小行星）截断光束形成阴影（`IsVisionBlockingHit`）
- 飞船对象不产生阴影：飞船模块（玩家/敌舰/残骸）一律不遮挡光束，被光束照到的飞船结构始终计入照明范围并完整显示（2026-08-04 更新）

### 渲染层（视野模块）

`SpaceshipVisionRenderFeature`（URP `ScriptableRendererFeature`）：

**渲染流程**：
1. `SpaceshipVisionMask.shader` → Stencil Buffer 写入圆形视野
2. `SpaceshipVisionPolygonMask.shader` → Stencil 写入多边形区域
3. `SpaceshipVisionPostProcess.shader` → 后处理暗角/边缘

**核心组件**：
- `SpaceshipVisionController` — 全局管理器（可见半径/开关/调试环/自动绑定 Target）
- `SpaceshipVisionTarget` — 挂飞船上，自动绑定 `ShipAssembly.CenterOfMass`
- `SpaceshipVisionPolygonRegion` — 额外可见多边形区域（运行时增删改）

**桥接**：
`PlayerShipVisionPolygonBridge`（玩法侧）将飞船数据传递给视野模块渲染系统。

## 雷达系统

`ShipSensorModules`（`Assets/Scripts/Gameplay/Ships/Combat/`）：

1. 玩家激活雷达（右键短按）
2. 广播 `RadarScanned` 事件（`ModuleEventSource`）
3. 载荷含发现敌舰列表 `ShipAssembly[]`
4. `RadarAcceptancePanel` UI 显示结果
5. 超时后标记过期

**过滤**：
- 只扫描不同阵营飞船
- 小行星在中间 → 目标被遮挡
- 敌方也可扫描玩家

## 世界生成

### SpaceshipWorldMap

`Assets/Scripts/Gameplay/World/SpaceshipWorldMap.cs`

| 参数 | 值 | 说明 |
|------|-----|------|
| 世界尺寸 | 500m × 500m | 方形边界 |
| 小行星 | 20-30 个 | 2-8m 随机半径 |
| 残骸 | 随机分布 | 随机模块配置，阵营 `Derelict` |

**小行星规则**：避开出生点、保持间距、静态 Rigidbody2D

**残骸规则**：`SalvageRandomizationManager` 控制随机化，可与玩家链接

## 星球交互

`PlanetDestination` — 管理降落/返航：
- 靠近新星球 → 按 F 降落（→ `ExpeditionComplete`）
- 靠近母星 → 按 F 返航（→ `ExpeditionComplete`）
