# UI 系统方案

> 定稿依据：游戏管理器方案《[游戏状态与流程](../核心循环/游戏状态与流程.md)》、评审定案记录《[UI 系统方案评审分析](./UI系统方案评审分析.md)》
> 更新：2026-08-02
>
> 本方案定义游戏中所有界面的布局、交互规则与数据来源。UI 系统不定义视觉风格与美术资产（小地图敌人显示色为暂定项，见 §4.1），只定义信息层级、控件交互逻辑和各界面之间的跳转关系。每个游戏状态对应一套 UI 布局，由游戏管理器触发切换。

---

## 状态与界面对照

| 游戏状态 | 对应界面 | 进入方式 |
|----------|----------|----------|
| 开始 | 开始界面 | 游戏启动 |
| 拼装 | 拼装界面 | 开始游戏（非首次）/ 结算返回 / 失败返回星球 |
| 飞行 | 游玩界面 | 首次游戏跳过拼装直接进入 / 点击出航 |
| 整理 | Tab 界面 | 飞行中按 Tab / 结算前强制进入 |
| 暂停 | 暂停界面 | 飞行或整理中按 Esc |
| 结算 | 结算界面 | 读条完成进入结算 |
| 失败 | 死亡界面 | 任一失败条件满足 |

---

## 1. 开始界面

游戏启动后显示的第一个界面。

### 数据

| 元素 | 说明 |
|------|------|
| 开始游戏 | 按钮 |
| 退出游戏 | 按钮 |

### 行为

| 行为 | 规则 |
|------|------|
| 点击开始游戏 | 调用游戏管理器的统一「开始游戏」入口；首次分支由管理器判定——首次游戏跳过拼装直接进入飞行，非首次进入拼装 |
| 点击退出游戏 | 通知游戏管理器执行退出 |

---

## 2. 拼装界面

玩家拼装飞船并装载货物的界面，在出航前使用。**「局内飞船配置」是拼装网格的唯一数据真源**。

### 数据

| 元素 | 说明 |
|------|------|
| 拼装网格 | 可放置模块的网格区域。已放置模块显示外观，空位显示为空白格 |
| 模块列表 | **模块库存**中的模块（局外资源），按类别分组显示 |
| 储存模块内容 | 以网格形式展示飞船储存模块内部格子的货物 |
| 出航按钮 | 点击后进入飞行状态 |
| 返回主菜单按钮 | 对应「拼装 → 开始」转移 |

### 拼装网格初始化（按进入路径加载）

| 进入路径 | 网格加载内容 |
|----------|--------------|
| 结算后再次出航 | 上一轮结算时的飞船配置与货物存储状态 |
| 失败后返回星球 | 预配置初始飞船 |
| 首次游戏 | 跳过拼装，直接进入飞行 |

### 行为

| 行为 | 规则 |
|------|------|
| 模块放置 | 从模块列表选择模块，拖入拼装网格目标位置 |
| 模块移除 | 将模块从拼装网格拖回模块列表，或右键点击移除 |
| 货物装载 | 从货物列表选择货物，拖入储存模块目标格子 |
| 货物取出 | 将货物从储存模块格子拖回货物列表 |
| 出航 | 点击出航按钮时**现场校验**：拼装结果至少包含一个核心模块。未通过时弹提示且**不切换状态**，提示文案：「无法出航：缺少核心模块」「请先放置至少一个核心模块再出航」 |
| 返回主菜单 | 点击返回主菜单按钮，通知游戏管理器切换至开始状态 |

### 货物操作语义

- 拼装界面的装卸**不产生丢弃**：货物在货物列表与储存槽位之间移动，仍归玩家所有。
- 仅 Tab 界面的拖出飞船边界才真正移除货物（见 §4.3）。

### 金币购买补给

拼装界面提供「金币购买补给」——食物 / 燃料 / 弹药三类消耗品可用金币购买补充；**模块不开放购买**（模块走残骸链接获得，保持玩法来源唯一）。

- 购买价格由策划填表，初期建议参考宝藏价值量级：一轮正常出航宝藏换算的金币，能购买约一轮消耗量的货物，让金币有稳定流出且不失控。

## 3. 游玩界面

玩家操控飞船航行时显示的主界面。信息层叠在游戏画面之上，不遮挡核心操作区域。

### 数据

| 元素 | 位置 | 内容 |
|------|------|------|
| 小地图 | 屏幕角落 | 见 §3.1 |
| 一天进度条 | 屏幕边缘 | 当前游戏内一天的剩余时间，以进度条形式表现，逐渐缩短 |
| 食物拥有数 | 与进度条相邻 | 当前飞船食物总量。每天结束时数字跳变减少，不足时变红闪烁 |
| 弹药拥有数 | 与食物相邻 | 当前飞船弹药总量。每次射击时数字跳变减少，不足时变红闪烁 |
| 燃料拥有数 | 与弹药相邻 | 当前飞船燃料总量。每行驶 100m 时数字跳变减少，不足时变红闪烁 |
| 交互提示 | 场景内 | 靠近可链接残骸时显示链接进度圈；拆卸钩爪可触发时显示对应提示 |

### 3.1 小地图

| 项目 | 规格 |
|------|------|
| 定位 | **局部雷达图** |
| 位置 | 屏幕角落 |
| 形状 | 圆形 |
| 尺寸 | 60m × 60m 世界范围 |
| 显示内容 | 雷达/照明侦测到的敌人、残骸与地形；自身飞船位置与朝向 |
| 自身飞船 | 始终位于圆心 |
| 敌人显示 | 亮橙色圆点（暂定，视觉表现层可调整） |
| 信号残留 | 信号消失后保留 5 秒逐渐消失 |

三档侦测半径（视野 / 照明 / 雷达）与 60m 视口的裁剪关系由程序实现。

### 3.2 资源预警（两档）

| 资源 | 资源不足（变红闪烁） | 即将失败（强提示） |
|------|----------------------|--------------------|
| 食物 | 剩余 ≤ 10（两日消耗量） | 剩余 ≤ 5（一日消耗量） |
| 燃料 | 剩余 ≤ 30% | 剩余 ≤ 10% |
| 弹药 | 剩余 ≤ 30% | 无（弹药归零不触发失败，不适用此档） |

### 行为

| 行为 | 规则 |
|------|------|
| 小地图更新 | 每帧根据飞船位置、朝向和当前视野范围更新；敌人位置在雷达扫描到或照明范围内时更新，信号消失后亮点保留 5 秒后逐渐消失 |
| 资源数值更新 | 消耗事件触发或拾取货物后实时更新（数据来源见文末程序附录） |

## 4. Tab 界面

玩家按 Tab 进入的货物管理界面。**呈现方式以既有《仓库整理界面》文档为准**（镜头放大聚焦储存模块、不弹面板），本方案仅定义其与状态机的衔接。

### 数据

| 元素 | 说明 |
|------|------|
| 储存模块内容 | 以网格形式展示各储存模块内部格子的货物，未鉴定货物以问号或灰暗图标显示 |
| 飞船展示 | 画面聚焦飞船，玩家可查看和管理储存模块中的货物（呈现方式遵循既有文档） |

### 4.1 进入与退出

| 项目 | 规则 |
|------|------|
| 进入 | 按 Tab 进入，游戏暂停 |
| 退出（普通路径） | 非结算流程：按 Tab 或 Esc 退出，回到飞行，游戏继续 |
| 退出（结算路径） | 结算前强制进入：玩家长按读条完成结算触发 → 货舱仍有未揭示货物 → 系统强制进入整理界面逐格揭示 → **揭示完成自动退出** → 跳转结算界面 |

### 4.2 揭示触发（三套并存）

| 触发 | 规则 |
|------|------|
| 史诗货物取得 | 取得史诗货物时强制打开并逐格鉴定（既有规则） |
| 首次进入 | 首次进入整理界面时触发货物首次揭示流程 |
| 结算前强制 | 触发结算时若存在未揭示物品，先进入整理界面揭示（§4.1 结算路径） |

三套触发并存；去重与优先级保护由程序实现保证。

### 4.3 货物管理

| 行为 | 规则 |
|------|------|
| 拖拽移动 | 可拖拽货物在储存模块格子之间移动（转移/合并/丢弃规则见既有《仓库整理界面》） |
| 拖出丢弃 | 可拖拽货物丢弃出飞船边界，货物真正从游戏中移除 |

## 5. 暂停界面

飞行或整理中按 Esc 后覆盖在当前画面上的界面。

### 数据

| 元素 | 说明 |
|------|------|
| 继续游戏 | 按钮 |
| 返回主菜单 | 按钮 |
| 退出游戏 | 按钮 |

### 行为

| 行为 | 规则 |
|------|------|
| 打开 | 按 Esc 打开，游戏暂停 |
| 关闭（继续） | **回到暂停前状态**：暂停前为飞行 → 回到飞行；暂停前为整理 → 回到整理。点击继续游戏或再次按 Esc 触发，游戏继续 |
| 返回主菜单 | 点击后通知游戏管理器切换至开始状态 |
| 退出游戏 | 点击后通知游戏管理器执行退出 |

---

## 6. 结算界面

玩家返回星球后展示的结算界面，显示本次探索成果。

### 数据

| 元素 | 说明 |
|------|------|
| 飞船展示 | 画面中展示返回时的飞船完整样貌（镜头定格呈现，见 §6.1） |
| 宝藏清单 | 列出本轮获得的所有宝藏名称、数量和价值 |
| 金币获得 | 显示本轮宝藏转换的金币总额 |
| 返回按钮 | 点击后返回拼装界面 |

### 行为

| 行为 | 规则 |
|------|------|
| 返回 | 点击返回按钮，通知游戏管理器切换至拼装状态 |

### 6.1 飞船展示（镜头定格）

进入结算/失败状态时保持当前相机视角，UI 面板作为覆盖层叠加，让玩家看到自己的飞船停在画面中。改动最小，复用现有 `ShipCameraFollower` 的冻结能力（失败冻结已是既有行为）。

### 数据链

金币总额由程序按既有约定实现：结算界面订阅 `CargoIdentifiedEvent` 按宝物稀有度查价值表显示价格，`CargoRevealCompleted` 后累计金币总额（见文末程序附录）。

## 7. 死亡界面

触发失败条件后展示的界面。

### 数据

| 元素 | 说明 |
|------|------|
| 失败原因 | 显示导致本次失败的具体原因 |
| 返回星球 | 按钮 |
| 返回主菜单 | 按钮 |

### 行为

| 行为 | 规则 |
|------|------|
| 返回星球 | 以游戏管理器方案为准：进入失败态时**即支付**预配置初始飞船费用（资金不足扣至 0、差额记欠账），点击返回星球后获得该预配置初始飞船并进入拼装状态；本次宝藏全部销毁、不进行结算 |
| 返回主菜单 | 点击后通知游戏管理器切换至开始状态 |

### 失败后的模块与货物

- **失败时模块与货物随飞船销毁**，与「失败→换取预配置初始飞船」的惩罚机制保持一致。
- 预配置初始飞船**自带的初始货物保留**，保证玩家仍有最低限度的出航资源。

**失败代价提示**：死亡界面应补充文案说明失败的经济代价（示例：「已更换为标准配置飞船，费用已从金币中扣除」），具体文案由策划定稿。

## 8. 与相关系统的衔接

| 系统 | 衔接点 |
|------|--------|
| 游戏管理器 | 各界面只调用管理器的状态切换入口（开始 / 出航 / 返回 / 退出），不自行判断分支规则（首次分支、结算路径等均由管理器裁决） |
| 模块库存 | 拼装界面模块列表的数据来源，局外资源，结算时入库；失败时随飞船销毁（见 §2、§7） |
| 货物库存 | 拼装界面货物列表的数据来源，局外资源，结算时入库（宝藏不纳入，已被结算换算为金币）；失败时随飞船销毁（见 §2、§7） |
| 金币 | 宝藏结算换算流入；拼装界面购买补给流出（消耗品，模块不开放购买）（见 §2） |
| 事件系统 | 游玩界面订阅食物/燃料/弹药/日进度事件；结算界面订阅货物鉴定事件（见文末程序附录） |
