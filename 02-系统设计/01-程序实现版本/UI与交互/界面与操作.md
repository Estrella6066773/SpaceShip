## 界面技术选型

当前所有 UI 基于 **`OnGUI()` 即时模式**（非 uGUI Canvas）。

**代码位置**：`Assets/Scripts/UI/`

## UI 组件清单

| 组件 | 类 | 功能 |
|------|-----|------|
| 主 HUD | `SpaceshipGameFlowController.OnGUI()` | 出航会话叠加界面（暂停/结算/失败面板；开始与拼装界面已迁往独立场景 `StartMenu` / `ShipBuild`） |
| 测试 HUD | `AssemblyPlaytestHud` | 飞船速度、资源（燃料/食物/弹药）、护盾状态、日进度条 |
| 工坊面板 | `ShipWorkshopPanel` | 工坊编辑模式界面 |
| 货物整理 | `CargoOrganizationController` | Tab 暂停 + 镜头放大 + 容器格就地拖拽整理界面 |
| 雷达面板 | `RadarAcceptancePanel` | 雷达扫描结果 ISX 显示面板 |
| 模块活动 | `ShipModuleActivityPresenter` | 模块开关/活动状态呈现 |

## 输入映射

基于 Unity Input System Package：

| 按键 | 功能 | 接收组件 |
|------|------|----------|
| W/S | 飞船前后移动 | `ShipMotionController` |
| A/D | 飞船左转/右转 | `ShipMotionController` |
| 鼠标左键 | 武器开火 | `ShipCombatController` |
| 鼠标右键短按 | 激活/关闭雷达或照明 | `ShipSensorModules` |
| 鼠标右键长按 | 拆卸模块（2 秒） | `ShipGrappleController` |

| E | 星球降落/母星返航 | `PlanetDestination` |

## 摄像机

`ShipCameraFollower`（`Assets/Scripts/Gameplay/Ships/Movement/ShipCameraFollower.cs`）：

| 行为 | 说明 |
|------|------|
| 跟随 | 飞船质心平滑跟随 |
| 旋转 | 旋转平滑跟随 |
| 震动 | 碰撞冲击抖动（`ShipCollisionFeedback`） |
| 冻结 | 飞船坠毁后冻结 |
| 缩放 | 组织界面开关时正交尺寸平滑缩放，`Time.unscaledDeltaTime` 驱动，暂停期间仍可过渡 |

组织模式缩放要点：

- 聚焦中心为所有储存模块的包围盒中心；飞船没有储存模块时退回几何中心
- 聚焦尺寸至少容纳储存模块包围盒并留出 `organizationPadding` 边距，但不小于 `focusOrthographicSize`（放大上限，默认 3.5）
- 参数可在 Inspector 调整：`focusOrthographicSize`、`focusZoomDuration`、`organizationPadding`

## 货物整理界面

`CargoOrganizationController`（`Assets/Scripts/UI/CargoOrganizationController.cs`）：

| 项目 | 说明 |
|------|------|
| 打开方式 | Tab 切换开/关，Esc 关闭 |
| 时间处理 | 打开时记录 `Time.timeScale` 并置 0 暂停；关闭时恢复 |
| 镜头 | `ShipCameraFollower.SetOrganizationMode` 平滑放大并冻结旋转，聚焦到储存模块 |
| 输入 | 打开时禁用移动、拼装交互与战斗；关闭时恢复 |
| 呈现 | 不再使用中央面板；在储存模块的 4 个格位世界位置投影绘制格子与货物图标（随镜头缩放） |
| 格位布局 | `SlotIndex` 0~3 对应模块本地坐标左上/右上/左下/右下（每格 0.5m×0.5m） |
| 拖拽 | 左键按住货物开始拖拽，幽灵图标跟随鼠标 |
| 转移到空格 | `ShipCargoHold.TransferToSlot` 返回 `MovedToEmptySlot` |
| 同类合并 | 目标格同类且有空余时合并，超上限部分留在原格（`MergedFull` / `MergedPartial`） |
| 目标被占用 | 不同类或已满时拒绝并弹回（`RejectedSlotOccupied`） |
| 丢弃 | 拖出所有容器格松开，`Drop` 移除槽位，物资直接视为从游戏中移除（不生成任何实体） |
| 揭示联动 | 史诗货物强制打开并锁定拖拽，逐格鉴定消息显示在屏幕底部，当前揭示格高亮 |
| 操作反馈 | 顶部信息条下方显示转移/合并/丢弃结果，2.5 秒后消失 |
