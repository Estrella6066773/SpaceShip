# 程序实现版本

本目录记录 **当前程序代码中实际实现的系统行为**，是从代码逆向分析得出的「实现了什么」。用于与设计版本对比，发现设计文档与代码之间的差距。

- **数据来源**：`d:\Unity\Spaceship` 工程中的 C# 脚本、Scene、Prefab、ScriptableObject
- **更新方式**：手动维护，当代码发生实质性改动时同步更新
- **角色**：设计对照基线，不参与云端同步
- **受众**：全体开发者（设计对照、Code Review 参考）

## 文档约定

- 每份文档以「当前实现」为口径，标注对应代码文件路径
- 若实现与设计存在差异，在文末标注「与设计的差异」
- 不包含设计意图、未来规划或未实现功能
