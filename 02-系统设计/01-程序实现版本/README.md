| [探索系统](./探索系统/) | 视野/光照/雷达、小行星生成、世界边界 |
| [UI与交互](./UI与交互/) | HUD 布局、输入映射、货物整理界面 |
| [世界系统](./世界系统/) | 场景管理、关卡生成、残骸系统 |

**约定：** 以「当前实现」为口径并标注代码路径；与设计差异在文末标注。
