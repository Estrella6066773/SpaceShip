## 视野/迷雾渲染系统（fog）

### 系统概览

基于 **URP ScriptableRendererFeature** 实现的自定义视野渲染系统，实现类似战争迷雾的飞船视野效果。系统由三个核心组件 + 三个 Shader 构成。

### 核心组件

#### SpaceshipVisionController

视野控制器单例，管理全局视野参数：

- **可见半径**：基础视野范围
- **效果开关**：运行时启用/禁用视野效果
- **调试模式**：可视化调试环
- **自动绑定**：启动时自动查找场景中的 `SpaceshipVisionTarget`

#### SpaceshipVisionTarget

挂载在飞船上的视野目标组件：

- 自动绑定 `ShipAssembly` 获取质心位置
- 计算可见半径（基础 20m + 照明模块扩展）
- 按标签过滤（`SpaceshipVisionIgnoreTag`）

#### SpaceshipVisionRenderFeature

URP 自定义渲染通道（`ScriptableRendererFeature`）：

- 在渲染管线中插入视野裁剪通道
- 使用 Stencil Buffer 实现多边形视野遮罩
- 后处理暗角效果

#### SpaceshipVisionPolygonRegion

多边形视野区域管理：

- 维护一组 `PolygonIsland` 区域数据
- 每个岛屿含：唯一 id、启用状态、Transform 覆盖、局部顶点列表
- 支持运行时增/删/改/清空操作
- 被渲染流程读取，作为额外可见区域参与视野计算

**对外接口**：

| 方法 | 说明 |
|------|------|
| `AddPolygonIsland(PolygonIsland)` | 新增或更新单个区域（id 去重） |
| `AddPolygonIslands(List<PolygonIsland>)` | 批量添加或更新 |
| `RemovePolygonIslandById(string id)` | 按 id 删除，返回是否成功 |
| `ClearPolygonIslands()` | 清空所有区域 |
| `PolygonIslands` (只读属性) | 获取当前区域列表 |

### Shader

| Shader | 用途 |
|--------|------|
| `SpaceshipVisionMask.shader` | 基础视野遮罩 |
| `SpaceshipVisionPolygonMask.shader` | 多边形视野遮罩 |
| `SpaceshipVisionPostProcess.shader` | 视野后处理（暗角/边缘效果） |

### 辅助组件

| 类型 | 用途 |
|------|------|
| `SpaceshipVisionIgnoreTag` | 标记需要忽略视野的物体 |
| `IgnoreSpaceshipVision` | 使特定物体不受视野系统影响 |
| `SpaceshipVisionSetupTool` | 编辑器设置工具（菜单：`wuqiwusheng/URP/创建 Polygon Region 预制体并放入场景`） |

## 序列图编辑器（SequenceMap）

### 系统概览

基于 **Unity UI Toolkit + GraphView** 构建的可视化流程图/行为图编辑器系统。是一个完整的自定义编辑器工具，支持多窗口停靠布局、代码生成、变量编辑。

### 编辑器窗口

| 窗口类 | 功能 |
|--------|------|
| `SequenceMapWorkspaceHostWindow` | 工作区宿主窗口（主容器） |
| `SequenceMapWorkspaceWindow` | 工作区窗口管理器（多窗口布局） |
| `SequenceMapGraphWindow` | 图形编辑主窗口 |
| `SequenceMapGraphView` | GraphView 核心节点视图 |
| `SequenceMapGraphListWindow` | 图形文件列表浏览 |
| `SequenceMapDetailsWindow` | 选中节点详情面板 |
| `SequenceMapVariablesWindow` | 变量编辑窗口 |
| `SequenceMapRecentGraphsWindow` | 最近打开图形记录 |
| `SequenceMapApiWindow` | API 浏览器 |
| `SequenceMapCanvasDebugWindow` | 画布调试窗口 |

### 基础设施

| 类型 | 用途 |
|------|------|
| `SequenceMapEditorWindowBase` | 所有编辑器窗口基类 |
| `SequenceMapEditorState` | 编辑器全局状态管理 |
| `SequenceMapDockingUtility` | 窗口拖拽停靠工具 |
| `SequenceMapPanelFactory` | 面板工厂（窗口创建） |
| `ResizablePanelManipulator` | 面板大小拖拽调整 |
| `ReorderablePanelContainer` | 可重排面板容器 |
| `MiddleMouseContentDragger` | 中键拖拽画布平移 |

### 高级功能

| 类型 | 用途 |
|------|------|
| `SequenceMapCodeGenerator` | 图形 → C# 代码生成器 |
| `SequenceMapApiRegistry` | 节点 API 注册表 |
| `SequenceMapApiAttribute` | API 标记特性（`[SequenceMapApi]`） |
| `SequenceMapGraphAssetOpenHandler` | 双击 .asset 打开图形编辑器 |
| `SequenceMapGraphSceneDragHandler` | 从场景拖拽对象到图形节点 |

### 运行时库

- `SequenceMapBaseLibrary` — 流程图运行时执行库（`Wuqiwusheng.SequenceMap` 命名空间）

## 敌舰行为系统（EnemyBehavior）

### EnemyBehaviorAttachTool

编辑器工具，用于批量为选中对象添加敌舰行为树组件：

- 菜单路径：`wuqiwusheng/EnemyBehavior/...`
- 功能：选择场景对象 → 自动添加 `EnemyShipBehaviorAuthoring` 组件

## 与 Kaki 系统的集成

wuqiwusheng 的系统通过以下方式与 Kaki 核心系统交互：

| 集成点 | 方式 |
|--------|------|
| 视野系统 ← 飞船数据 | `Kaki.Spaceship.PlayerShipVisionPolygonBridge` 桥接组件 |
| 视野目标绑定 | `SpaceshipVisionTarget` 自动查找 `ShipAssembly` |
| 敌舰行为树 | `EnemyBehaviorAttachTool` 为 Kaki 的敌舰预制体添加行为组件 |
| 序列图编辑器 | 独立编辑，可生成供 Kaki 系统调用的 C# 代码 |
