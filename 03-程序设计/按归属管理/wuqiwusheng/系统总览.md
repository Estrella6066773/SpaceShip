## 视野/迷雾渲染系统（fog）

### 系统概览

基于 **URP ScriptableRendererFeature** 实现的自定义视野渲染系统，实现类似战争迷雾的飞船视野效果。系统由三个核心组件 + 三个 Shader 构成。

### 核心组件

#### SpaceshipVisionController

视野控制器，管理全局视野参数：

- **可见半径**：基础视野范围
- **效果开关**：运行时启用/禁用视野效果
- **调试模式**：可视化调试环
- **绑定方式**：混合模式——启动时自动查找场景中的 `SpaceshipVisionTarget`（按 `Player` Tag），同时暴露显式 `SetTarget(SpaceshipVisionTarget)` 供手工装配覆盖

#### SpaceshipVisionTarget

挂载在飞船上的视野目标组件：

- 自动绑定 `ShipAssembly` 获取质心位置（支持 `targetOverride`）
- 计算可见半径（船体最远点到质心距离 ÷ 系数 + 附加半径）
- 按标签过滤（`SpaceshipVisionIgnoreTag`）

#### SpaceshipVisionRenderFeature

URP 自定义渲染通道（`ScriptableRendererFeature`），RenderGraph 四通道：

1. **多边形通道**：`SpaceshipVisionPolygonMask.shader` 画多边形可见区域遮罩
2. **遮罩通道**：`SpaceshipVisionMask.shader` 写入 Stencil Buffer（Ref 1）
3. **后处理通道**：`SpaceshipVisionPostProcess.shader` 按屏幕像素半径做视野裁剪 + 调试环描边
4. **恢复通道**：把忽略 Layer 的对象画回原色

#### SpaceshipVisionPolygonRegion

多边形视野区域管理（场景单例）：

- 维护一组 `PolygonIsland` 区域数据
- 每个岛屿含：唯一 id、启用状态、Transform 覆盖、局部顶点列表
- 自带 ear-clipping 三角化与 Mesh 缓存
- 支持运行时增/删/改/清空操作

**对外接口**：

| 方法 | 说明 |
|------|------|
| `AddPolygonIsland(PolygonIsland)` | 新增或更新单个区域（id 去重） |
| `AddPolygonIslands(List<PolygonIsland>)` | 批量添加或更新 |
| `RemovePolygonIslandById(string id)` | 按 id 删除，返回是否成功 |
| `ClearPolygonIslands()` | 清空所有区域 |
| `PolygonIslands` (只读属性) | 获取当前区域列表 |

### Shader

| Shader | 用途 |
|--------|------|
| `SpaceshipVisionMask.shader` | 基础视野遮罩（Stencil 写入） |
| `SpaceshipVisionPolygonMask.shader` | 多边形视野遮罩 |
| `SpaceshipVisionPostProcess.shader` | 视野后处理（暗角/边缘效果） |

### 辅助组件

| 类型 | 用途 |
|------|------|
| `SpaceshipVisionIgnoreTag` | 标记需要忽略视野的物体（切到 `SpaceshipVisionIgnore` Layer） |
| `IgnoreSpaceshipVision` | 使特定物体不受视野系统影响 |
| `SpaceshipVisionSetupTool` | 编辑器设置工具（菜单：`wuqiwusheng/URP/...`，创建预制体/渲染特性资产并注入 RendererData） |

## 敌舰行为系统（EnemyBehavior）

### 系统概览

**状态机框架**（非行为树）：以纯 C# 状态机 `EnemyShipBehaviorController` 为核心，通过 `IEnemyShipRuntime` 接口与飞船组件解耦。同一套状态机有两个宿主：

- **Kaki 侧 `EnemyShipController`**（当前实际接入场景的实现）：直接实现 `IEnemyShipRuntime`，并由传感器通过 `IEnemyShipBehaviorDriver.OnScannedBy` 反扫描驱动
- **wuqiwusheng 侧 `EnemyShipBehaviorAuthoring`**（并行替代方案）：自带私有 `RuntimeAdapter`，可禁用 Kaki 内置控制器，提供更丰富的 Gizmo 调试可视化

### 状态机架构

```
EnemyBehaviorPhase: Normal → Scan → Battle → Escape
```

| 主阶段 | 子阶段 |
|--------|--------|
| `Normal` | Patrol / ReturnHome / WaitAtHome |
| `Scan` | MoveToLastKnown → MoveToSearchPoint → Rotate →（循环）→ WaitAfterLoops → ReturnHome |
| `Battle` | Chase → Fire → WaitAfterShot → Reposition → Fire … |
| `Escape` | 远离玩家采样可达点逃跑，期间始终朝玩家转向 |

**转换规则**：
- 感知驱动抢占：有玩家且可见时，有炮 → Battle；无炮 → Escape
- 巡逻中按 `walkScanInterval` 雷达反扫描，发现则进入 Scan
- 战斗丢视野：雷达能补位则 Scan，超 `lostSightDelay` 仍无结果则回家恢复巡逻
- 玩家消失：立即恢复 Normal 巡逻

### 类型清单

| 类型 | 位置 | 职责 |
|------|------|------|
| `EnemyBehaviorSettings` | `EnemyShipBehaviorContext.cs` | 行为参数配置（24 个字段，全中文 Tooltip，按巡逻/扫描/战斗/逃跑/采样/驱动分组） |

| `EnemyBehaviorContext` | 同上 | 状态上下文（家点/目标点/计时器/循环计数等全部运行时状态） |
| `EnemyShipBehaviorController` | `EnemyShipBehaviorController.cs` | 状态机核心（`Tick()` / `ResetHome()` / `Phase`） |

## 与 Kaki 系统的集成

wuqiwusheng 的系统通过以下方式与 Kaki 核心系统交互：

| 集成点 | 方式 |
|--------|------|
| 视野系统 ← 飞船数据 | `Kaki.Spaceship.PlayerShipVisionPolygonBridge` 桥接组件 |
| 视野目标绑定 | `SpaceshipVisionTarget` 自动查找 `ShipAssembly` |
| 敌舰行为 | `Kaki.Spaceship.EnemyShipController` 实现 `IEnemyShipRuntime`（wuqiwusheng 定义），由行为状态机驱动 |
| 敌舰反扫描 | Kaki 传感器通过 `IEnemyShipBehaviorDriver.OnScannedBy` 回调驱动行为框架进入搜索阶段 |
| 序列图编辑器 | 独立编辑，可生成供游戏调用的 C# 代码（`SequenceMapGraphRunner` 运行时执行） |
