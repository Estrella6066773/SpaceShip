## 核心系统

### SpaceshipGameManager

```102:115:d:\Unity\Spaceship\Assets\Kaki\Scripts\Core\SpaceshipGameManager.cs
public class SpaceshipGameManager : MonoBehaviour
{
    // 游戏总管理器，持有 SpaceshipGameConfiguration 引用
    // 负责协调游戏启动、场景初始化
}
```

**职责**：游戏总入口管理器，持有 `SpaceshipGameConfiguration`，协调全局初始化流程。

### SpaceshipGameFlowController

状态机管理四个互斥状态：

| 状态 | 触发 | 允许操作 | 失败/转移条件 |
|------|------|----------|--------------|
| `Title` | 运行时构建完成 | 开始游戏、退出 | → Expedition |
| `Expedition` | 点击开始 | 驾驶/战斗/交互 | 核心摧毁/动力全毁/燃料耗尽/食物不足 → Failure；降落/返航 → Complete |
| `ExpeditionComplete` | 降落或返航 | 再来一局、退出 | → Title |
| `Failure` | 生存条件失败 | 再来一局、退出 | → Title |

### TemporaryGameDirector

游戏导演组件，负责：
- 5 分钟日循环计时
- 每日食物结算（消耗 5 食物）
- 玩家飞船初始化
- 事件源查找与验证

### ShipSceneRegistry

场景飞船名册，管理三类飞船注册：
- **玩家飞船**：通过 ShipAssembly 注册
- **敌舰**：通过 EnemyShipController 注册
- **残骸**：通过 ShipAssembly 注册（阵营为 Derelict）

### ShipWorkshopModeController

编辑/操控模式切换器，控制工坊内飞船的两种运行模式。

### LevelContentInitializationController

5 阶段关卡初始化流程：
1. 随机模块槽位填充
2. 货物初始化
3. 飞船注册
4. 导演系统启动
5. 视野系统激活

## 事件系统

事件系统采用**分类事件源 + C# event** 模式，由抽象基类 `SpaceshipEventSource` 统一派生。

```
SpaceshipEventSource (abstract MonoBehaviour)
├── ShipFlowEventSource    → 飞船流程事件
├── ModuleEventSource      → 模块事件
└── CargoEventSource       → 货物事件
```

### 事件定义

所有事件载荷均定义为 `readonly struct`（零堆分配），定义在 `SpaceshipEventSource.cs` 中：

| 事件 | 载荷关键字段 | 广播时机 |
|------|------------|----------|
| `ShipSpawned` | shipAssembly | 飞船生成完成 |
| `ShipDestroyed` | shipAssembly, reason | 飞船被摧毁 |
| `ModulesChanged` | shipAssembly, changedModule, changeDescription | 模块链接状态变更 |
| `ModuleDestroyed` | shipAssembly, module, destroyReason | 单个模块被摧毁 |
| `CargoChanged` | cargoHold, slotIndex, item | 货物数量变化 |
| `EpicCargoAcquired` | item, cargoHold | 获得史诗级宝物 |
| `CargoRevealStarted` / `CargoIdentified` / `CargoRevealCompleted` | cargoHold, slotIndex | 货物鉴定流程 |
| `RadarScanned` | faction, ships | 雷达扫描完成 |
| `DayEnded` | playerShip, foodBalance | 每日结算 |
| `GameStateChanged` | prevState, nextState | 游戏状态切换 |
| `ExpeditionCompleted` | arrivalLocation | 出航完成 |

### 架构约束

- EventSource 不得引用订阅者（单向广播）
- UI、Audio、FX 通过事件订阅解耦，不得被玩法系统直接调用
- 事件源实例由 Director 查找并验证，禁止全局单例

## 飞船系统

### 组装系统（Ships/Assembly）

**ShipAssembly** — 飞船总成，管理所有子模块：
- 管理 `ShipModule[]` 子模块列表
- 实时计算总质量与质心位置
- 重建模块链接关系
- 处理飞船摧毁逻辑
- 判断阵营归属（Player/Enemy/Derelict/Neutral）

**ShipModule** — 飞船模块组件：
- 1 米网格坐标与旋转
- 四向链接点（Forward/Right/Back/Left）
- 生命值与四档损坏精灵图
- 碰撞体与物理交互
- 功能类型引用（`ModuleDefinition` SO）

**ShipAssemblyInteractionController** — 飞船交互控制器：
- 对接手动链接与拆卸
- 管理链接碰撞检测
- 处理链接引导线反馈

### 模块类型（ModuleKind）

| 枚举值 | 中文名 | 功能 | 特殊能力 |
|--------|--------|------|----------|
| `Core` | 核心模块 | 飞船必须品 | 被摧毁则飞船坠毁 |
| `Thruster` | 动力模块 | 四向推进 | 根据位置产生力矩（杠杆原理） |
| `Radar` | 寻敌雷达 | 环境感知 | 可开关，扫描不同阵营 |
| `Light` | 发散光束 | 视野扩大 | 60°/80m 照明范围 |
| `Cannon` | 固定式机炮 | 武器 | 弹药，冷却，射程限制 |
| `Grapple` | 拆卸钩爪 | 模块操作 | 长按 2 秒拆卸模块 |
| `Shield` | 电磁盾 | 防御 | 反弹弹丸与雷达信号 |
| `Storage` | 储存模块 | 物资管理 | 4 槽位，各类货物 |
| `Empty` | 基础模块 | 纯质量 | 仅提供生命/装甲 |

### 物理运动（Movement）

**ShipMotionController** — 基于 `Rigidbody2D` + Input System：
- WASD 坦克式操作（A/D 旋转，W/S 前后）
- 动力模块数 × 推力系数 → 推力
- 核心模块推力作用于质心（不产生力矩）
- 超载惩罚：模块数 > loadCapacity 时推力衰减

## 数据定义（DataRuntime）

共 8 个 ScriptableObject 类型定义，是游戏配置的核心：

| 类型 | 继承 | 职责 |
|------|------|------|
| `ModuleDefinition` | `ScriptableObject` | 模块定义（种类/质量/生命/功能/预制体引用），含 `ModuleKind`、`LocalDirection`、`CargoType`、`ShipFaction` 枚举 |
| `ShipBlueprint` | `ScriptableObject` | 飞船蓝图（模块网格布局 + 初始货物配置） |
| `SpaceshipGameConfiguration` | `ScriptableObject` | 游戏总配置（组合所有子配置） |
| `SpaceshipWorldRules` | `ScriptableObject` | 世界规则（地图/昼夜/物理参数/视野/雷达/小行星） |
| `PlayerShipSettings` | `ScriptableObject` | 玩家飞船行为参数 |
| `ShipWorkshopLibrary` | `ScriptableObject` | 工坊资料库 |
| `CargoSlotConfiguration` | `ScriptableObject` | 货物槽位配置 |
| `CargoItemDefinition` | `ScriptableObject` | 货物物品定义 |

### 关键枚举

| 枚举类型 | 值 |
|----------|-----|
| `ModuleKind` | Empty, Core, Thruster, Radar, Light, Cannon, Grapple, Shield, Storage |
| `LocalDirection` | Forward, Right, Back, Left |
| `CargoType` | Food, Fuel, Ammunition, Treasure |
| `ShipFaction` | Derelict, Player, Enemy, Neutral |
