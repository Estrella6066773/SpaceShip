# 程序设计

技术实现设计，按领域分类。命名空间统一 `Spaceship.<Module>`；分层 asmdef。模式见 [模块分层与粘合代码模式](./按领域分类/架构设计/模块分层与粘合代码模式.md)。

## 领域

| 目录 | 范围 |
|------|------|
| [架构设计](./按领域分类/架构设计/) | 整体架构、分层、迁移与剪枝 |
| [模块设计](./按领域分类/模块设计/) | 飞船、事件、战斗、视野、任务、API 等 |
| [数据设计](./按领域分类/数据设计/) | ScriptableObject 配置体系 |
| [工具与编辑器](./按领域分类/工具与编辑器/) | 工具清单、入口管理 |
| [规范与标准](./按领域分类/规范与标准/) | 编码规范概要 |

## 原则

显式装配 · 接口隔离 · 数据驱动 · 可测试 · 命名空间/程序集边界。
