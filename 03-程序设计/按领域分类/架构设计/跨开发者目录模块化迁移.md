# 跨开发者目录模块化迁移

> 日期：2026-08-02 | 状态：已落地

彻底摈弃按程序员（Kaki / wuqiwusheng / Mailk）划分的目录结构，在 `Assets` 根部按标准游戏系统结构重组全部代码与资源，统一命名空间为 `Spaceship.<Module>`，建立分层 asmdef，删除已归档的 Mailk 原型。

## 目标目录结构

```
Assets/
├── Scripts/                          # Spaceship.* 运行时与编辑器脚本
│   ├── Core/                         # Spaceship.Core
│   ├── Gameplay/                     # Spaceship.Gameplay（飞船/敌人/世界/工坊）
│   ├── UI/                           # Spaceship.UI
│   ├── Events/                       # Spaceship.Events
│   ├── DataRuntime/                  # Spaceship.Data
│   ├── Configs/                      # Spaceship.Configs
│   ├── Vision/                       # Spaceship.Vision（原 wuqiwusheng/fog 渲染）
│   ├── Tools/                        # Spaceship.Tools
│   └── Validation/                   # Spaceship.Validation
├── Framework/                        # 通用框架（可迁移）
│   ├── AudioFramework/               # Spaceship.Framework.Audio
│   ├── FXFramework/                  # Spaceship.Framework.FX
│   ├── EventBinding/                 # Spaceship.Framework.EventBinding
│   └── SequenceMap/                  # Spaceship.Framework.SequenceMap
├── Art/  Prefabs/  Scenes/  Data/  Documentation/  Settings/
```

## asmdef 程序集边界

```
运行时
├── Spaceship.Framework.EventBinding     Framework/EventBinding/
├── Spaceship.Framework.Audio            Framework/AudioFramework/    → EventBinding
├── Spaceship.Framework.FX               Framework/FXFramework/       → EventBinding
├── Spaceship.Framework.SequenceMap      Framework/SequenceMap/
└── Spaceship.Game                       Scripts/（含 Vision）         → Audio、FX、InputSystem、URP
编辑器（仅 Editor 平台）
├── Spaceship.Framework.EventBinding.Editor
├── Spaceship.Framework.Audio.Editor     → Audio、EventBinding、EventBinding.Editor
├── Spaceship.Framework.FX.Editor        → FX、EventBinding、EventBinding.Editor
├── Spaceship.Framework.SequenceMap.Editor
├── Spaceship.Game.Editor                → Game、TMPro
├── Spaceship.Validation.Editor          → Game
└── Spaceship.Vision.Editor              → Game、URP
```

要点：

- `Scripts/Vision` 与 `Scripts/Gameplay` 存在双向数据引用（玩法桥接视野渲染、视野消费玩法数据），故 Vision 并入 `Spaceship.Game` 单一程序集，统一引用 URP，避免程序集循环依赖。
- `TriggerActionAttribute` 迁入 `Framework/EventBinding`，消除 EventBinding ↔ FX 循环依赖。
- Editor 代码按模块目录建立独立 Editor 程序集，仅 Editor 平台。

## 删除与清理

- 删除整个 `Assets/Mailk` 目录（8 脚本 + SampleScene），构建入口切换为 `Assets/Scenes/Test/ShipTest.unity`。
- 清理死代码：`SpaceshipVisionRenderFeature` 的 `URP_COMPATIBILITY_MODE` 兼容分支、一次性迁移工具 `GameplayScriptLayoutMigrator`、空目录。
- 更新全部硬编码旧路径工具与菜单归属（`Kaki/...`、`wuqiwusheng/...` → `Spaceship/...`）。
