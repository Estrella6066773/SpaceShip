# 世界与视野系统

> 作者：代码分析生成 | 创建日期：2026-07-29 | 最后修改：2026-07-29

本文档描述 Spaceship 项目的世界生成、视野渲染与感知系统的技术设计。

---

## 系统概览

世界系统负责地图生成与物理边界，视野系统负责飞船的感知范围渲染。二者协作构成探索玩法的基础。

---

## 世界系统（Kaki）

### SpaceshipWorldMap

世界地图管理器，维护以下内容：

| 参数 | 值 | 说明 |
|------|-----|------|
| 世界尺寸 | 500m × 500m | 方形边界 |
| 小行星数量 | 20-30 个 | 随机生成 |
| 小行星大小 | 2-8m 半径 | 不可破坏障碍物 |
| 残骸生成 | 随机分布 | 随机阵营/随机模块配置的废船 |

#### 小行星生成规则

- 避开玩家出生位置（留出安全区域）
- 小行星之间保持最小间距
- 小行星为静态 Rigidbody2D 障碍物
- 可遮挡视野（物理碰撞 + 视野阻断）

#### 残骸系统

残骸由 `SalvageRandomizationManager` 控制：
- 随机模块类型与布局
- 阵营固定为 `Derelict`
- 玩家可与其链接碰撞体接触 → 自动链接
- 被拆卸后的模块 60 秒内可更快重新链接

## 视野系统

视野系统由两个开发者协作实现：
- **Kaki**：视野数据计算（范围/雷达/照明）
- **wuqiwusheng**：视野渲染（URP RenderFeature + Shader）

### Kaki 侧数据层

#### SpaceshipVisibilityController

管理飞船的感知数据：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 基础视野半径 | 20m | 所有飞船都有 |
| 雷达扫描范围 | 100m | 需安装雷达模块并激活 |
| 照明角度 | 60° | 发散光束扇面角度 |
| 照明范围 | 80m | 发散光束有效距离 |
| 雷达过期时间 | 可配置 | 扫描结果有效期 |

#### 遮挡规则

- 小行星遮挡雷达信号（物理射线检测）
- 照明采用单射线遮挡检测（原型方案）

### wuqiwusheng 侧渲染层

#### 架构

```
SpaceshipVisionController (全局管理器)
    │
    ├── SpaceshipVisionTarget (单体视野目标)
    │       └── 自动绑定 ShipAssembly.CenterOfMass
    │
    ├── SpaceshipVisionRenderFeature (URP RenderFeature)
    │       ├── Stencil Buffer 写入（遮罩）
    │       ├── 多边形视野区域（额外可见区）
    │       └── 后处理暗角
    │
    └── SpaceshipVisionPolygonRegion (多边形区域管理)
            └── PolygonIsland[] (多个可见多边形岛屿)
```

#### RenderFeature 渲染流程

1. **遮罩通道**：使用 `SpaceshipVisionMask.shader` 将视野范围写入 Stencil Buffer
2. **多边形通道**：使用 `SpaceshipVisionPolygonMask.shader` 将 PolygonRegion 区域写入 Stencil
3. **后处理通道**：使用 `SpaceshipVisionPostProcess.shader` 基于 Stencil 进行暗角处理

#### 三种 Shader

| Shader | 用途 | 渲染阶段 |
|--------|------|----------|
| `SpaceshipVisionMask` | 圆形视野遮罩 | BeforeRendering |
| `SpaceshipVisionPolygonMask` | 多边形区域遮罩 | BeforeRendering |
| `SpaceshipVisionPostProcess` | 后处理暗角/边缘 | AfterRendering |

### 数据桥接

Kaki 通过 `PlayerShipVisionPolygonBridge` 组件将飞船质心位置、视野范围等数据传递给 wuqiwusheng 系统：

```
ShipAssembly → PlayerShipVisionPolygonBridge → SpaceshipVisionTarget → RenderFeature
```

## 雷达系统

### 工作原理

1. 玩家激活雷达模块（右键短按）
2. `ShipSensorModules` 调用 `ModuleEventSource.RadarScanned` 事件
3. 事件载荷包含扫描到的敌舰列表（`ShipAssembly[]`）
4. `RadarAcceptancePanel` UI 面板显示结果
5. 扫描结果有过期时间，过期后标记无效

### 扫描过滤

- 只扫描与扫描方阵营不同的飞船
- 小行星遮挡：如果小行星在扫描方和目标之间，目标被隐藏
- 敌方雷达同样可以扫描玩家

## 敌舰 AI

### EnemyShipController

状态机驱动的敌舰 AI：

```
┌──────────┐   发现目标    ┌──────────┐
│  Patrol  │ ───────────► │ Tracking │
│ (巡航)   │              │ (追踪)   │
└──────────┘              └────┬─────┘
     ▲                         │
     │    失去目标             │ 摧毁
     │  ◄────────────────────  │
     │                         ▼
     │                    ┌──────────┐
     └─────────────────── │Destroyed │
                          │ (已摧毁) │
                          └──────────┘
```

#### 巡航模式（Patrol）

- 在预设巡逻路径点之间移动
- 定时自动雷达扫描
- 发现玩家 → 转入追踪模式

#### 追踪模式（Tracking）

- 持续追踪目标位置
- 自动开火（调用 `ShipCombatController`）
- 距离过远或目标消失 → 退回巡航
