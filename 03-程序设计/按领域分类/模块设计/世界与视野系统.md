# 世界与视野系统

> 作者：代码分析生成 | 创建日期：2026-07-29 | 最后修改：2026-08-02

本文档描述 Spaceship 项目的世界生成、视野渲染与感知系统的技术设计。

---

## 系统概览

世界系统负责地图生成与物理边界，视野系统负责飞船的感知范围渲染。二者协作构成探索玩法的基础。

---

## 世界系统

### SpaceshipWorldMap

世界地图管理器，维护以下内容：

| 参数 | 值 | 说明 |
|------|-----|------|
| 世界尺寸 | 500m × 500m | 方形边界 |
| 小行星数量 | 20-30 个 | 随机生成 |
| 小行星大小 | 2-8m 半径 | 不可破坏障碍物（`AsteroidObstacle` 标记） |
| 残骸生成 | 随机分布 | 随机阵营/随机模块配置的废船（`GenerateModuleGroup` 按链接面随机生长 1-5 模块） |

#### 小行星生成规则

- 避开玩家出生位置（留出安全区域）
- 小行星之间保持最小间距
- 小行星为静态 Rigidbody2D 障碍物
- 可遮挡视野（`IsVisionBlocked` 物理碰撞 + 视野阻断）

#### 残骸系统

残骸由 `SalvageRandomizationManager` 控制：
- 随机模块类型与布局（固定种子权重随机，默认 20260728）
- 阵营固定为 `Derelict`
- 玩家可与其链接碰撞体接触 → 自动链接（残骸模块 60 秒内可更快重新链接）
- 被拆卸后的模块可被钩爪携带或安装

## 视野系统

视野系统分两层协作：
- **感知层**：视野数据计算（范围/雷达/照明），见 [感知数据层](#感知数据层)
- **渲染层**：视野渲染（URP RenderFeature + Shader），见 [渲染层](#渲染层)

### 感知数据层

#### SpaceshipVisibilityController

管理飞船的感知数据：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 基础视野半径 | **动态**（质心到最远船体端 + `hullVisionPadding`） | 不再固定 20m |
| 雷达扫描范围 | 100m | 需安装雷达模块并激活 |
| 照明角度 | 60° | 发散光束扇面角度 |
| 照明范围 | 80m | 发散光束有效距离 |
| 雷达过期时间 | 可配置 | 扫描结果有效期 |

呈现方式：
- 使用 **SpriteMask** 呈现视野遮罩，船只在遮罩内可见，小行星始终可见
- 若视野模块 `SpaceshipVisionController` 开启，则改用其 RenderFeature 表现

#### 遮挡规则

- 小行星遮挡雷达信号（物理射线检测）
- 照明采用单射线遮挡检测（`ShipLightVisibilityGeometry` 统一计算光束几何）

### 渲染层

#### 架构

```
SpaceshipVisionController (全局管理器)
    │
    ├── SpaceshipVisionTarget (单体视野目标)
    │       └── 自动绑定 ShipAssembly.CenterOfMass
    │
    ├── SpaceshipVisionRenderFeature (URP RenderFeature)
    │       ├── Stencil Buffer 写入（遮罩）
    │       ├── 多边形视野区域（额外可见区）
    │       └── 后处理暗角
    │
    └── SpaceshipVisionPolygonRegion (多边形区域管理)
            └── PolygonIsland[] (多个可见多边形岛屿)
```

#### RenderFeature 渲染流程（RenderGraph 四通道）

1. **多边形通道**：使用 `SpaceshipVisionPolygonMask.shader` 将 PolygonRegion 区域写入遮罩纹理
2. **遮罩通道**：使用 `SpaceshipVisionMask.shader` 将视野范围写入 Stencil Buffer（Ref 1）
3. **后处理通道**：使用 `SpaceshipVisionPostProcess.shader` 按屏幕像素半径做视野裁剪 + 调试环描边
4. **恢复通道**：把忽略 Layer 的对象画回原色

#### 三种 Shader

| Shader | 用途 | 渲染阶段 |
|--------|------|----------|
| `SpaceshipVisionMask` | 圆形视野遮罩 | BeforeRendering |
| `SpaceshipVisionPolygonMask` | 多边形区域遮罩 | BeforeRendering |
| `SpaceshipVisionPostProcess` | 后处理暗角/边缘 | AfterRendering |

### 数据桥接

`PlayerShipVisionPolygonBridge` 组件将玩家启用光束的几何同步为视野模块的 `SpaceshipVisionPolygonRegion` 多边形区域，并按事件脏标记/遮挡间隔刷新：

```
ShipAssembly → ShipLightVisibilityGeometry.TryBuildLocalPolygon
    → PlayerShipVisionPolygonBridge → SpaceshipVisionPolygonRegion → RenderFeature
```

## 雷达系统

### 工作原理

1. 玩家激活雷达模块（右键短按）
2. `ShipSensorModules` 自动扫描（`RadarCooldown`）或 `TriggerImmediateScan` 手动
3. 广播 `RadarScanned` 事件（载荷：`ship`/`position`/`radius`）
4. `RadarAcceptancePanel` UI 面板显示结果
5. 扫描结果有过期时间，过期后标记无效

### 扫描过滤

- 只扫描与扫描方阵营不同且**存活核心**的飞船
- 小行星遮挡：如果小行星在扫描方和目标之间，目标被隐藏
- 敌方雷达同样可以扫描玩家
- 护盾可反射雷达信号（接触点保留 `RadarMarkerDuration`）
- **反扫描回调**：被扫描方通过 `IEnemyShipBehaviorDriver.OnScannedBy` 获知被扫，行为框架据此进入搜索阶段

## 敌舰 AI

### EnemyShipController（敌舰决策入口）

敌舰控制器实现敌人行为框架的 `IEnemyShipRuntime` 接口，由 `EnemyShipBehaviorController` 状态机驱动（四阶段：Normal → Scan → Battle → Escape）。详见 [整体架构](../架构设计/整体架构.md)。

```
┌──────────┐   发现目标    ┌──────────┐
│  Normal  │ ───────────► │  Battle   │
│ (巡航)   │              │ (战斗)    │
└────┬─────┘              └────┬─────┘
     │  玩家丢失               │ 无炮
     │  ◄──────────────────    ▼
     │                    ┌──────────┐
     └───────────────────►│  Escape  │
                          │ (逃跑)   │
                          └──────────┘
```

补充转换：
- 巡逻中雷达反扫描发现目标 → **Scan**（搜索）→ 追踪到后进入 Battle
- Battle 中丢失视野：雷达能补位则回 Scan，超时无结果则回 Normal 巡航

#### 巡航模式（Normal / Patrol）

- 在家点周围随机采样可达巡逻点移动
- 按 `walkScanInterval` 定时雷达反扫描
- 发现玩家 → 有炮进 Battle，无炮进 Escape

#### 战斗模式（Battle）

- Chase（追到环绕圈）→ Fire（停船转向开炮）→ WaitAfterShot → Reposition（周围采样可达点）
- 失去视野 → 雷达补位进 Scan 或超时回巡航

#### 逃跑模式（Escape）

- 远离玩家采样可达点逃跑
- 期间始终朝玩家方向旋转（看得见转视线、看不见转雷达点）
