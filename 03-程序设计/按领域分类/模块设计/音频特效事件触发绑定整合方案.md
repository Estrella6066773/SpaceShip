# 音频特效事件触发绑定整合方案

> 作者：代码分析生成 | 创建日期：2026-08-02 | 最后修改：2026-08-02
>
> **状态：已落地**（2026-08-02 模块化迁移中完成）——共享绑定模块现位于 `Framework/EventBinding/`，命名空间 `Spaceship.Framework.EventBinding`。

本方案把 AudioFramework 与 FXFramework 中重复的「事件触发绑定」逻辑收敛为共享基础模块 `Framework/EventBinding`，让 AudioPlayer 与 FXPlayer 复用同一套运行时绑定与编辑器候选收集逻辑。

模式定义见 [模块分层与粘合代码模式](../架构设计/模块分层与粘合代码模式.md)。

---

## 现状与问题

AudioFramework 与 FXFramework 都提供「把组件上的事件绑定到回调」的能力，但各自维护了一份逐行相同的反射代码：

| 模块 | 组件 | 绑定能力 | 编辑器候选收集 |
|------|------|----------|----------------|
| AudioFramework | `AudioPlayer` | C# event / UnityEvent → 播放回调 | `AudioEventPlayerEditor` |
| FXFramework | `FXPlayer` | C# event / UnityEvent → `[TriggerAction]` 方法 | `FXManagerEditor` |

### 重叠点 1：运行时反射绑定重复

`AudioPlayer` 与 `FXPlayer` 各自实现了同一组反射辅助方法：

| 方法 | 职责 |
|------|------|
| `ResolveEventComponent` | 从事件源（Component / GameObject）解析实际持有事件的对象 |
| `TryGetUnityEvent` | 从组件读取 UnityEvent 字段或属性 |
| `TryAddUnityEventListener` / `TryRemoveUnityEventListener` | 反射增删 UnityEvent 监听 |
| `CreateDelegate` | 用 Expression 构造「忽略参数」委托 |

两份实现逐行相同，是典型的「粘合代码出现大量重复，说明背后应存在独立能力模块」场景。

### 重叠点 2：编辑器事件候选收集重复

两个自定义 Inspector 各自实现 `GetEventCandidates` / `CollectCandidates` / `FormatSignature` / `FormatUnityEventSignature`，从事件源列出可绑定事件。同样逐行相同。

## 目标结构

```
Framework/
  EventBinding/
    EventBindingUtility.cs              运行时绑定工具（共享）
    Editor/
      EventBindingEditorUtility.cs      Editor 事件候选收集（共享）

AudioFramework/                         FXFramework/
  Core/AudioPlayer.cs ─────────────┐      Core/FXPlayer.cs ────────────┐
    └─ EventBindingUtility ◄───────┘        └─ EventBindingUtility ◄────┘
  Editor/AudioEventPlayerEditor.cs ─┐      Editor/FXManagerEditor.cs ────┐
    └─ EventBindingEditorUtility ◄──┘        └─ EventBindingEditorUtility ◄┘
```

- `EventBindingUtility`：运行时事件绑定，`AudioPlayer` 与 `FXPlayer` 共用。
- `EventBindingEditorUtility`：编辑器事件候选收集，两个自定义 Inspector 共用。
- 命名空间：`Spaceship.Framework.EventBinding`（运行时）、`Spaceship.Framework.EventBinding.Editor`（Editor）。

> 放置位置说明：项目规范要求通用框架位于 `Framework/<FrameworkName>`。EventBinding 是 Audio/FX 共享的基础框架模块，因此放在 `Assets/Framework/EventBinding/`，与 `AudioFramework`、`FXFramework` 并列，而不是挂在某个具体框架或玩法目录下。

## 共享模块设计

### `EventBindingUtility`（运行时）

| 方法 | 职责 |
|------|------|
| `ResolveEventComponent` | 从事件源解析实际持有事件的对象（缓存组件 → Component → GameObject 全组件查找） |
| `TryBindEvent` | 绑定事件到回调；优先 C# event，其次 UnityEvent；成功后回写缓存引用 |
| `Unbind` | 解绑事件并清空缓存引用 |
| `TryGetUnityEvent` | 从组件读取 UnityEvent（字段或属性） |
| `CreateDelegate` | 用 Expression 构造「忽略参数」的委托（事件返回 void 即可） |

绑定过程保留原有的回退与告警语义：

- 事件源是 Component：直接使用。
- 事件源是 GameObject：在其所有组件中查找包含该事件名的组件；多个匹配时使用第一个并告警。
- 事件签名不支持（非 void 返回）时告警并跳过。

### `EventBindingEditorUtility`（Editor）

| 成员 | 职责 |
|------|------|
| `EventCandidate` | 事件候选结构（Source / Name / Display） |
| `GetEventCandidates` | 从组件或 GameObject 收集全部可绑定事件候选 |
| `FormatSignature` / `FormatUnityEventSignature` | 事件签名格式化 |

收集规则与原先两个 Editor 一致：仅显示 public 事件 / UnityEvent（隐藏私有成员），按「类型名.成员名 (签名)」格式展示。

## 各组件调整

### `AudioPlayer`

- 删除内部反射辅助方法：`ResolveEventComponent`、`TryGetUnityEvent`、`TryBindEvent`、`TryAddUnityEventListener`、`TryRemoveUnityEventListener`、`CreateDelegate`。
- 事件绑定改调 `EventBindingUtility.TryBindEvent`，解绑改调 `EventBindingUtility.Unbind`。
- `using System.Linq.Expressions` 不再需要，替换为 `using Spaceship.Framework.EventBinding`。

### `FXPlayer`

- 删除内部反射辅助方法：`ResolveEventComponent`、`TryGetUnityEvent`、`TryAddUnityEventListener`、`TryRemoveUnityEventListener`、`CreateDelegate`。
- 绑定 / 解绑改调 `EventBindingUtility`。
- `using System.Linq.Expressions` 不再需要，替换为 `using Spaceship.Framework.EventBinding`。

### `AudioEventPlayerEditor`

- 删除内部候选收集：`GetEventCandidates`、`CollectCandidates`、`FormatSignature`、`FormatUnityEventSignature`、`EventCandidate`。
- 改调 `EventBindingEditorUtility.GetEventCandidates`。
- `using UnityEngine.Events` 替换为 `using Spaceship.Framework.EventBinding.Editor`。

### `FXManagerEditor`

- 删除内部事件候选收集：`GetEventCandidates`、`CollectEventCandidates`、`FormatEventSignature`、`FormatUnityEventSignature`、`EventCandidate`。
- 改调 `EventBindingEditorUtility.GetEventCandidates`。
- 保留 `MethodCandidate` 与方法候选收集（`[TriggerAction]` 方法候选是 FX 独有能力，不属于共享范围）。
- `using UnityEngine.Events` 替换为 `using Spaceship.Framework.EventBinding.Editor`。
