# 战斗系统

> 作者：代码分析生成 | 创建日期：2026-07-29 | 最后修改：2026-08-02

本文档描述 Spaceship 项目战斗系统的技术设计，包括武器、防御、钩爪与弹丸系统。

---

## 系统概览

战斗系统围绕「模块化飞船→模块化战斗」的理念设计。每个武器/防御模块是独立的 ShipModule，通过 `ModuleKind` 区分功能。战斗流程由 `ShipCombatController` 统一协调。

---

## 组件结构

```
ShipAssembly
├── ShipCombatController      # 开火协调器（含喷焰灼烧）
├── ShipShieldController      # 护盾控制
├── ShipGrappleController     # 钩爪控制
├── ShipSensorModules         # 雷达 + 照明
├── ShipLightVisibilityGeometry # 光束几何计算（静态库）
└── Projectile2D              # 弹体（独立对象）
```

## 武器系统

### ShipCombatController

负责所有武器模块的协调：

| 职责 | 说明 |
|------|------|
| 从左键输入到开火 | 读取 Input System→检查冷却→检查弹药→生成弹体 |
| 冷却管理 | 每个武器模块独立冷却计时 |
| 弹药管理 | 从 `ShipAmmunitionConsumptionManager` 读取弹药状态 |
| 喷焰视觉 | `UpdateThrusterFlames` 动力模块喷焰表现 |
| **喷焰灼烧伤害** | `DamageBehindThruster`：动力模块尾部对附近敌舰造成持续伤害（0.1s/次，1 点伤害） |

### 武器类型

| 武器 | ModuleKind | 弹体 | 冷却 | 弹药 | 射程 |
|------|-----------|------|------|------|------|
| 固定式机炮 | `Cannon` | `Projectile2D` | 有 | 消耗弹药 | 有限 |

### Projectile2D

2D 弹体行为：
- 直线飞行（基于发射方向）
- 碰撞检测
- 命中伤害计算
- 自毁范围

## 护盾系统

### ShipShieldController

护盾功能：
- 每块电磁盾**独立充能**（按 `ShieldCapacity` 上限恢复）
- `TryReflectProjectile`：按模块局部坐标计算反射法线反弹弹丸
- `TryReflectRadar`：反弹敌方雷达信号并消耗 `ShieldReflectionCost` 能量
- 盾面方向配置（Forward/Right 两个护盾面）

## 钩爪系统

### ShipGrappleController

钩爪是拆卸工具模块：

| 操作 | 触发方式 | 行为 |
|------|----------|------|
| 激活钩爪 | 对准范围内敌人模块自动作用 | 持续 `GrappleActionDuration` 秒拆卸成残骸 |
| 拆卸完成 | 作用时间结束 | 目标模块从 ShipAssembly 分离并**携带**（`AttachCarriedAssembly`） |
| 携带残骸 | 拆卸后不释放 | 被拆模块跟随钩爪，计入总质量 |
| 安装模块 | 寻找敌船空闲链接位 | 通过 `TryTransferSingleModuleFrom` 重新链接 |
| 抓取独立残骸 | 直接对准 | 抓取独立残骸模块 |

状态通过 `Status`/`ActionProgress01`/`CooldownRemaining` 暴露。

**限制**：不可拆卸核心模块。

## 传感器系统

### ShipSensorModules

管理感知类模块（雷达、照明）：

| 传感器 | ModuleKind | 功能 | 操作 |
|--------|-----------|------|------|
| 寻敌雷达 | `Radar` | 100m 范围扫描，只发现**不同阵营且存活核心**的目标 | 按 `RadarCooldown` 自动扫描或 `TriggerImmediateScan` 手动 |
| 发散光束 | `Light` | 60° 扇面 × 80m 照明 | 右键短按开关 |

雷达特性：
- 命中护盾会被反射（接触点保留 `RadarMarkerDuration`）
- **反扫描回调**：`NotifyScannedTarget` 把被扫描事实发给目标上的 `IEnemyShipBehaviorDriver.OnScannedBy`，驱动敌舰行为框架进入搜索阶段
- 扫描事件载荷：`RadarScanEvent`（`ship`/`position`/`radius`）

### ShipLightVisibilityGeometry

**纯静态几何库**（无状态），统一计算：
- 发散光束的发光面
- 扇形多边形（供视野桥接）
- 遮挡命中（模块/小行星，`ShipLightBlockHit` 记录命中物）

供 `ShipSensorModules`、`PlayerShipVisionPolygonBridge`、`ShipModuleActivityPresenter` 三处共用。

## 伤害规则

### 敌我伤害

- 玩家子弹 → 伤害敌人模块
- 敌人子弹 → 伤害玩家模块
- 友军伤害：默认不开启
- 动力模块尾部喷焰 → 对附近敌舰持续灼烧伤害

### 核心爆炸

- 核心模块被摧毁时，对以核心为中心的 **3×3 网格（相邻八格）** 内的其他模块造成爆炸伤害
- 伤害数值由核心模块的 `ModuleDefinition.CoreExplosionDamage` 配置，默认 **100 点**
- 溢出伤害可被吸收：伤害超出模块剩余生命值时，模块直接摧毁，多余伤害不传递
- 爆炸结算完成后广播 `CoreExplodedEvent`（载荷含核心模块、爆炸中心世界坐标、伤害值），供 VFX / 音频订阅
- 爆炸伤害先于飞船坠毁结算，相邻模块的连锁摧毁正常走 `SplitDisconnectedGroups` 流程

### 摧毁规则

| 条件 | 结果 |
|------|------|
| 单个模块生命归零 | 模块被摧毁，可能触发链式断裂（`SplitDisconnectedGroups`） |
| 核心模块被摧毁 | 先对相邻八格造成核心爆炸伤害，随后整艘飞船坠毁 → `ShipDestroyed` 事件 |
| 所有动力模块被摧毁 | 整艘飞船坠毁 → `ShipDestroyed` 事件 |
| 燃料耗尽 / 食物不足 | 整艘飞船坠毁 → `ShipDestroyed` 事件 |
