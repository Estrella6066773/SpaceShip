# 战斗系统

> 作者：代码分析生成 | 创建日期：2026-07-29 | 最后修改：2026-07-29

本文档描述 Spaceship 项目战斗系统的技术设计，包括武器、防御、钩爪与弹丸系统。

---

## 系统概览

战斗系统围绕「模块化飞船→模块化战斗」的理念设计。每个武器/防御模块是独立的 ShipModule，通过 `ModuleKind` 区分功能。战斗流程由 `ShipCombatController` 统一协调。

---

## 组件结构

```
ShipAssembly
├── ShipCombatController      # 开火协调器
├── ShipShieldController      # 护盾控制
├── ShipGrappleController     # 钩爪控制
├── ShipSensorModules         # 雷达 + 照明
└── Projectile2D              # 弹体（独立对象）
```

---

## 武器系统

### ShipCombatController

负责所有武器模块的协调：

| 职责 | 说明 |
|------|------|
| 从左键输入到开火 | 读取 Input System→检查冷却→检查弹药→生成弹体 |
| 冷却管理 | 每个武器模块独立冷却计时 |
| 弹药管理 | 从 `ShipAmmunitionConsumptionManager` 读取弹药状态 |
| 推进器尾焰伤害 | 动力模块尾焰对附近敌舰造成持续伤害 |

### 武器类型

| 武器 | ModuleKind | 弹体 | 冷却 | 弹药 | 射程 |
|------|-----------|------|------|------|------|
| 固定式机炮 | `Cannon` | `Projectile2D` | 有 | 消耗弹药 | 有限 |

### Projectile2D

2D 弹体行为：
- 直线飞行（基于发射方向）
- 碰撞检测
- 命中伤害计算
- 自毁范围

## 护盾系统

### ShipShieldController

护盾功能：
- 吸收前方/右侧弹丸伤害
- 反弹敌方雷达信号
- 能源消耗与自动恢复
- 盾面方向配置（Forward/Right 两个护盾面）

---

## 钩爪系统

### ShipGrappleController

钩爪是拆卸工具模块：

| 操作 | 触发方式 | 行为 |
|------|----------|------|
| 激活钩爪 | 右键长按目标模块（非核心） | 持续锁定 2 秒 |
| 拆卸完成 | 2 秒后 | 目标模块从 ShipAssembly 分离 |
| 携带残骸 | 拆卸后不释放 | 被拆模块跟随钩爪，计入总质量 |
| 安装模块 | 将携带的模块对接空闲链接面 | 重新链接到 ShipAssembly |

**限制**：不可拆卸核心模块。

## 传感器系统

### ShipSensorModules

管理感知类模块（雷达、照明）：

| 传感器 | ModuleKind | 功能 | 操作 |
|--------|-----------|------|------|
| 寻敌雷达 | `Radar` | 100m 范围扫描敌方飞船 | 右键短按开关 |
| 发散光束 | `Light` | 60° 扇面 × 80m 照明 | 右键短按开关 |

## 伤害规则

### 敌我伤害

- 玩家子弹 → 伤害敌人模块
- 敌人子弹 → 伤害玩家模块
- 友军伤害：默认不开启

### 伤害计算

```
最终伤害 = 基础伤害 × (1 + 质量修正) - 护盾吸收
```

- 质量修正：重型模块减少受到的伤害
- 护盾吸收：如果命中面有护盾，优先消耗护盾能量

### 摧毁规则

| 条件 | 结果 |
|------|------|
| 单个模块生命归零 | 模块被摧毁，可能触发链式断裂 |
| 核心模块被摧毁 | 整艘飞船坠毁 → `ShipDestroyed` 事件 |
| 所有动力模块被摧毁 | 整艘飞船坠毁 → `ShipDestroyed` 事件 |
