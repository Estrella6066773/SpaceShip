Spaceship 的独立文档库（与 `d:\Unity\Spaceship` 工程分离）。

## 板块

| 板块 | 聚焦 | 入口 |
|------|------|------|
| [设定设计](./01-设定设计/README.md) | 世界观、叙事、美术（是什么） | 明/暗线双轨 |

## 编写约定

- 格式：Markdown；图片放同目录 `images/`
- 文首可注作者与日期；跨板块用相对路径引用
- **设定文档职责**：总览=导航；正文=骨架；词条=细节权威；待定项汇总=全局待定唯一索引（见 [设定设计 README](./01-设定设计/README.md)）

## 与工程关系
