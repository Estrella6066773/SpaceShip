## 文档编写约定

1. **文件格式**：统一使用 Markdown (`.md`)，文件名使用中文描述
2. **图片资源**：放置于同目录下的 `images/` 子文件夹中
3. **版本信息**：每份文档顶部注明作者、创建日期、最后修改日期
4. **关联引用**：跨板块引用使用相对路径，例如 `[拼装系统](./02-系统设计/01-程序实现版本/飞船系统/拼装与模块.md)`

## 与程序代码库的关系

- 程序代码位于 `d:\Unity\Spaceship`
- 已有的开发规范、实现文档、审查记录保留在工程目录 `Assets/Documentation/` 中
- 新增设计文档优先放置于本仓库相应板块
- 逐步将工程内的历史设计文档迁移至本仓库并归入对应板块
