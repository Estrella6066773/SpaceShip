## 核心玩法速览

> Spaceship 是一款 **2D 物理驱动的飞船拼装与太空探索战斗游戏**。

- **拼装**：在 1 米网格上自由组合 9 种模块，形成自定义飞船
- **操作**：WASD 移动、鼠标瞄准射击、Tab 切换武器、数字键激活交互
- **探索**：20m 基础视野 + 60°/80m 光照 + 100m 雷达，500m×500m 世界边界
- **战斗**：机炮弹丸、护盾反弹、钩爪拆解、尾焰持续伤害
- **生存**：燃料消耗、食物日结、模块损坏与修理
