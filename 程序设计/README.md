## 设计原则

根据项目规范，以下原则应在所有程序设计文档中贯彻：

1. **显式装配优先于自动查找**：组件依赖通过 Inspector 显式装配，减少隐式 Find/Singleton
2. **接口隔离**：模块间通过接口契约通信，禁止跨开发者目录直接耦合
3. **数据驱动**：游戏逻辑由 ScriptableObject 配置驱动，代码不硬编码数值
4. **可测试性**：核心逻辑应可独立于 MonoBehaviour 进行单元验证
5. **命名空间隔离**：每位开发者的代码位于各自命名空间下（Est / Kaki / wuqiwusheng / Mailk）
