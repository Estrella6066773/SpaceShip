## 明线写作约定

1. **驾驶员视角**：明线内容是驾驶员看到、听到、相信的世界；驾驶员不知道的（战争全貌、势力内情、身份真相），明线不展开。
2. **不泄底**：明线文档不出现任何暗线信息（无人站点、人工智能真相、刺探任务、白手套交易等）。
3. **背景只作传闻**：涉及战争、外部势力时，以站上社会如何叙述的口径呈现，设定细节指向暗线。
4. **双层词条**：凡明暗两面都重要的词条，暗线另存一份真相版本，并经由 [明暗对照表](../00-总览/明暗对照表.md) 互链。
