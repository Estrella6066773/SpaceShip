## 核心结论速查

- 云上人 = 思维上传的人类（**人类**）；人工智能 = **非人类**（含被制造的智能存在与不合规上传者）。
- 身份由「合规上传 + 官方授权」决定，而非「你有没有上传过」。
- A 站失去合法授权通道，逃难者只能不合规上传，沦为非法人工智能。
- 人格化人工智能在云上人社会被明令禁止；逃难者为自保打破禁令。
