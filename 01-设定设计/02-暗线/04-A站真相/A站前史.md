# A 站前史：从采冰站到中转空间站

> ⚠️ 暗线（真相）内容，**不得**直接用于玩家可见文案。表层认知见 [明线 · 空间站A](../../01-明线/空间站/空间站A.md) 的「A 站的由来」节。

## 概述

战前环带上的一家小采冰公司，从一颗冰质小行星起家，数年间扩张为「三座采冰站 + 一座中转空间站」的格局——这座中转空间站即 A 站的前身，一座名副其实的边陲小城。采冰公司是**环带本地产业，灾变前后都正常运营**（大灾变切断的是跨轨道航道，采冰公司的航线是环带内部短途航线，未受直接冲击）。

本前史覆盖从公司起家到中转空间站建成、再到战争摧毁一切的完整时间跨度（决议六十一）。

---

## 第一阶段：起家

采冰公司的事业，始于一颗中等大小的冰质小行星。

那时站上只有约 **1500 到 2000 人**——整颗小行星，就是公司的全部家当。工人们在上面架设采集设施、切割冰块、装船运输，日子简单而紧凑。

## 第二阶段：扩张

公司渐渐做大，工人慕名而来，很快便涨到了 **约 2500 人**。原先那颗小行星已经挤不下了。

于是公司开始物色下一颗冰质小行星——这次他们找了一颗体积更大、含水量更高的，并开始使用**巨企N 的技术**进行勘探与采集。这是 A 站与巨企N 最早的实质联系：技术依附，从冰质小行星的勘探与采集开始。

## 第三阶段：招工与再扩张

第二颗小行星投入开发时，最初的采冰站已经人满为患。恰在这时，附近的原生人工人们刚从巨企的自动化工厂里被赶出来——自动化流水线落地（降本增效）让他们的岗位消失了，而云上人作为自动化受益者接手了那些岗位。听说这里招工，这批失业工人便都跑了过来。

公司只好派了近一半的人去第二颗小行星，以便容纳这批人，同时着手准备开发第三颗小行星——这一颗比前两颗都大，够挖上更久。

至此，采冰公司的人力结构发生了关键变化：**巨企N 自动化淘汰的工人，成了采冰公司扩张的劳动力来源**（决议六十四）。

## 第四阶段：战争来临

就在第三颗小行星的开发步入轨道时，**环带内战**打响了。

"环带内战"——在矿工们的日常里，这是一个听着夸张的词。在很长一段时间里，它只是工人们的饭后谈资，完全没有影响采冰站的运作。毕竟战场在环带的另外一头，跟这座边陲小站隔着很远、很远。

## 第五阶段：转型为中转空间站

当第三颗小行星的采冰工作步入正轨时，**最初的那颗采冰站也快被开采殆尽了**。

公司做了一个早已规划的决定：将最初搭建的结构从小行星中脱离出来，把采冰工人和他们的装备送到刚完成勘探的第四颗小行星上，然后把原站点改造为一座中转空间站，迁到三颗冰质小行星的中心位置。

到这时，空间站已经稳定有 **2000 到 3000 人**居住，负责给三座采冰站提供所需的一切物资——名副其实的边陲小城。**这座中转空间站，就是后来的 A 站。**

---

## 关键时序

```
采冰站（人类，1500–2000人）
    → 扩张（引入巨企N技术，派驻云上人技术团队）
    → 再扩张（吸纳被自动化淘汰的失业工人）
    → 环带内战爆发（长期未波及采冰站区域）
    → 转型为中转空间站（2000–3000 人，边陲小城）
    →【环带大战波及 A 站区域】→ A 站受袭、被动脱离巨企N
    → 数月封锁 → 思维上传逃难 → 虚拟社会构建
```

虚线之后的进程（被动脱离 → 上传 → 虚拟社会）由既有决议覆盖（决议二十六、决议二十七等），本前史覆盖的是虚线之前的部分。

## 时间位置

- 全部内容发生在**战前 → 战时早期**（环带内战打响后，采冰站仍正常运作）。
- **与大灾变的关系**：采冰公司是环带本地产业，灾变前后都正常运营——大灾变切断的是跨轨道航道（法厄同环与近地/马尔斯轨道失联），而采冰公司的航线是环带内部短途航线，灾变后仍可用。采冰业不受跨轨道失联的直接冲击（决议六十一）。
- 与 [暗线·时间线](../暗线·时间线.md) 的关系：本前史填充了现有时间线中「A 站被动脱离」**之前**的空白段，插入「战前」阶段。

---

## 采冰业的终结

采冰业**死于战争，而非市场**——矩阵联合坚壁清野波及采冰设施与矿区后，A 站失去采冰来源与物资供应，采冰公司实际解体，幸存者被迫转向打捞残骸维生。这不是产业升级，是被战争从「生产者」打成了「拾荒者」。

采冰站上的小行星工人（约 3000–4000 人）在坚壁清野中的结局（幸存并上传 / 覆灭）尚未确定，将影响真实幸存者构成。

以下待定项通过本前史已获解决：

- [x] **A 站依附于巨企N 的具体形态** → 技术依附：巨企N 向采冰公司提供冰质小行星的勘探与采集技术，并派驻云上人技术团队驻站（设备维护、技术指导、数据回传）
- [x] **空间站A 的战前历史** → 已由本前史五个阶段完整交代
- [x] **原生人工人被赶出工厂的前因** → 自动化取代，云上人接手岗位（决议六十四）
- [x] **人口衔接**（中转空间站 2000–3000 → 虚拟社会 6000–8000） → 增长靠捏造 AI 补足，真实幸存者仅 1000–1500（见 [虚拟社会](虚拟社会.md)）
- [x] **被动脱离的接续** → 矩阵联合坚壁清野（决议四十五），采冰业同时终结
