## 暗线写作约定

1. **背景与真相**：暗线文档描述玩家视角之外的世界（战争、势力、真相），不与明线叙事混写。
2. **明确标记**：文档头部标注「暗线」，表示含剧透，禁止流入玩家可见文案。
3. **双线对照**：双层设定经由 [明暗对照表](../00-总览/明暗对照表.md) 与明线词条互链。
