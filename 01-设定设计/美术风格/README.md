# 美术风格

本目录定义 Spaceship 的统一视觉语言：低饱和工业太空、功能性人工照明，以及清晰的像素化归纳。它是叙事、美术、界面与技术实现共用的执行依据，而不是单纯的灵感收集。

## 使用原则

1. **先读总基调，再读专业规范。** 所有角色、场景、载具与界面都遵循同一套颜色角色和信息优先级。
2. **结构先于装饰。** 模块、接缝、支架、舱门、线路和设备本身构成细节；避免无功能的花纹填充。
3. **光必须有功能。** 黄白工作灯、红色告警灯、青色电子光都用于定位、分区或传达状态，不作为无意义的环境光。
4. **参考图提取原则，不直接复制。** 每张图只用于所列的视觉要点；构图、题材、品牌元素和不符合世界观的部分均不继承。

## 资产维护

- 所有图片保留在 `.image/` 下，文档只使用相对路径引用，不移动、不重命名。
- 新增参考图时，必须补充“参考用途、不可照搬、状态”，并链接到对应主题文档。
- `.aseprite` 文件属于可编辑源工程；每次将其纳入正式规范前，都应导出 PNG 预览供非 Aseprite 使用者审阅。
