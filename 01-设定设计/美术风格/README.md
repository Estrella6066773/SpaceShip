# 美术风格

本板块沉淀 Spaceship 项目的**视觉方向与美术规范**,面向叙事策划、美术、程序等团队成员,是设定设计板块「视觉先行」设计原则的落点。

---

## 板块定位

- **是什么**:项目希望长成的样子——整体视觉基调、场景风格、UI 语言、角色造型、载具材质
- **为什么**:统一各成员的视觉想象,降低跨角色沟通成本,防止美术产出与世界观设定脱节
- **受众**:叙事策划(理解场景氛围与叙事的视觉锚点)、美术(风格准绳与参考索引)、程序(环境光照、材质、UI 实现的依据)

## 参考图库约定

1. **图片原位存放**:全部参考图位于 `image/` 下,**不移动、不重命名**,引用一律使用相对路径
2. **文件名即语境**:部分文件名携带原始判断(如「?」「不宜用作」「参考价值低」),**以文档内的「状态」字段为准**,不以文件名为依据
3. **状态三态**:`采用`(可作执行准绳)、`待决议`(方向可用,细节未定)、`不采用`(仅作反例/记录,不进入成品)
4. **新增参考图**:图片放入 `image/`,并在本 README 的图库索引中登记一行,注明参考点与状态
