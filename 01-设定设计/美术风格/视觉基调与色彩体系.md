# 视觉基调与色彩体系

## 概述

Spaceship 的整体视觉基调:以**深空冷色调为底、工业金属质感为骨、人工光源点缀为眼**。世界发生在大灾变后的环带星区,画面气质偏「宏大、疏离、金属、人工」,而非田园或暖调。

## 特征

### 1. 整体气质

- **宏大与疏离**:太空港、环带、小行星均以大体量结构示人,人物在画面中占比小,强调宇宙尺度下的孤独感
- **工业金属感**:建筑与载具以金属结构、桁架、模块拼接为主,弱化有机与圆润造型
- **人工光源点缀**:在深色金属环境中,以灯光、舷窗光、推进器火光作为视觉锚点与暖色点缀

### 2. 配色方向

| 色彩 | 定位 | 说明 |
|------|------|------|
| 深空黑 / 墨蓝 | 底色 | 画面主体背景,提供对比与纵深 |
| 金属灰 / 冷钢色 | 结构色 | 建筑、飞船、设施的通用材质色 |
| 暖橙 / 琥珀 | 点缀色 | 人工灯光、推进器火焰、舷窗光,小面积使用 |
| 警示红 / 科技青 | 强调色 | 用于 UI、危险标识、信号灯等关键信息 |

> 配色原则:**冷底暖点**。冷色铺满,暖色只在小面积、有叙事或功能意义处出现,保证「灯亮起来」时的视觉回报。

### 3. 光影基调

- 全局以偏冷的空间光为主,阴影硬朗、明暗对比强
- 人工光源(灯、屏、火焰)承担主要暖色贡献,形成「冷环境 + 暖光源」的对比结构
- 参考动态印象图可看出光照是画面氛围的关键变量,而非静态贴图(见下)

## 风格要点(提炼)

1. 画面底色以深空黑 / 墨蓝为主,避免大面积纯白或高饱和背景
2. 结构件统一为金属冷色系,材质差别靠表面处理(磨损、氧化、涂装)区分,不靠色相跳跃
3. 暖色严格限量:灯光、火焰、信号为唯一暖色来源,保证每一处暖色都有「位置感」
4. 光照优先于贴图:氛围靠光不打靠贴图,动态光照是风格的一部分而非可选增强

## 待定

- 冷色的具体色相倾向(墨蓝偏青还是偏紫)待第一批场景原型后定稿

- 动态光照的落地程度(实时光 vs 烘焙光)需与程序侧视野/光照系统方案对齐
