## 一句话定位

整个故事是一只「罐头社会」的尺度：**一个约几千人的封闭空间站，漂浮在战后环带的一小段废墟里，靠打捞维持紧平衡的生存，同时被矿业联盟当骚扰工具使唤——而站上没有一个人知道自己是人还是程序。**

规模应呈现「小镇感」而非「城市感」：让每张脸孔都可能重要，让独裁落在每个人头上，让觉醒（反叛者）成为奇迹。

## 二、空间规模（距离）

故事舞台是环带（法厄同环带）的**一段弧区**，不是整条环带：

| 尺度 | 建议 |
|---|---|
| 故事区段 | 环带中约 **0.2–0.5 AU**（约 3000 万–7500 万公里）的一段 |
| A 站本体 | 主体直径 **1–2 km** 的大型空间站（轮状/环形 + 悬挂工业舱段 + 船坞），总展开 3–5 km |
| 日常打捞作业半径 | **500–3000 公里**（推荐千公里级），残骸稠密区 |
| 远程刺探目标（巨企N残存辖区 / 矿业联盟枢纽） | 距 A 站 **0.01–0.05 AU**（150 万–750 万公里），单程 3–10 天 |
| 近地轨道 / 马尔斯轨道 | AU 级，灾变后失联，故事中不可达（纯背景） |

### 环带的地形：带状结构（沿海 / 深海模型）

环带是位于黄道面附近的**扁平带状（盘状）结构**，航行因此分成两套截然不同的环境：

- **带内（小行星密布区）＝ 陆地 / 沿海**：地形复杂、有大天体遮蔽，行动受限、航程短，如同在陆地或沿海行动——战机级飞行器在此游走，依托天体掩护；
- **带外（环带内缘上下的开阔空间）＝ 大海**：开阔、可自由机动、可长途直线航行，如同在大海中航行——这是「舰船」的领域。

**「舰船」的界定**：真正意义上的「舰船」指**中大型飞船，拥有脱离环带、在环带内缘直线航行的能力**——即能下「深海」做长途航行的远洋船，需要充足的补给与远距离航行能力。但这条能力**只在非战时有意义**：平时站间通航、长途运输靠它。**在环带内部，舰船反而没有优势**——小行星带像陆地/沿海，更适合灵活的小型单位（战机级）活动；中大型飞船在带内目标大、机动笨重、补给负担重。战时战线被带状结构拉平（见战争规模一节），舰船沦为平面战线上的消耗品。

### 航行分档（三档工具）

| 档位 | 环境 | 工具 | A 站相关 |
|---|---|---|---|
| 作业单位（战机级） | 带内，作业半径数百–数千公里 | 战机级飞行器 / 无人机（灵活的小型单位） | A 站数百台无人机 = 驾驶员躯体；不自飞长途 |
| 带内运载（运输机） | 带内摆渡：A 站 ↔ 活动地点往返，数百–数千公里；中程任务可达 0.01–0.05 AU、单程数天 | 运输机 / 母机（搭载多架战机，自带航程与补给） | A 站持有**十至数十架运输机**，是驾驶员往返 A 站与作业区的「班车」 |
| 带外深海（舰船） | 环带内缘上下的开阔空间，AU 级长途 | 舰船（中大型，远洋） | 战后基本瘫痪 / 稀缺；A 站无 |

**玩家的往返机制**：玩家战机（无人机）**不自行往返 A 站**——出站作业时，运输机将玩家战机搭载至活动地点（数百–数千公里，数小时航程），作业完成后由运输机接回。战机被击落时，运输机回收信号/残骸、带回站内（呼应「复活」机制的物理层）。

**关键自洽点**：灾变后以太航行失效，只有传统推进（约 1–5 km/s 量级），所以**战后活动半径必须小**——带内日常活动维持在千公里级。这让「环带大战横跨整片环带」（战时靠战机级沿带长途出击，舰船从带外深海切入）与「战后驾驶员只能在家门口打捞」（带内残骸密布、由运输机摆渡往返）不矛盾；远程刺探虽达 0.01–0.05 AU（单程数天），仍由运输机负责中程摆渡、沿途利用残骸中转站补给，与日常打捞节奏自然拉开。

另外，小行星带天然天体间距是百万公里级，但 A 站周边是**战场残骸区**——战机级残骸、结构件密布，千公里内打捞目标充足，这个密度是自洽的。

## 三、人口规模（人数）

A 站虚拟社会总人口建议 **3000–5000 人**：

| 群体 | 建议人数 | 依据 |
|---|---|---|
| 普通居民（拟人化人工智能） | 2000–4000 | 虚拟社会是「小社会」（设定原文），构成群众基础 |
| 驾驶员（玩家群体，在役） | **200–500** | 直接补上待定项「驾驶员群体数量的控制」 |
| 自由政府（逃难者＝非法人工智能） | 50–200（决策核心十余人） | 「战后绝境中站上剩下的人」，不是千军万马 |
| 学社（技术官僚） | **30–80** | 硬约束：设定明言「人数稀少」 |
| 千化教会驻站 | 20–60 | 外部势力，规模小 |
| 反叛者 | **1–20**（潜伏） | 硬约束：设定明言「极少数」 |

**实体站人数：0**——无活人肉身，所有人都是数字存在。

### 为什么不是几万几十万

- **资源约束**：空间站靠打捞维生、能源紧张（「剩余资源只能勉强维持循环」是设定原文），几千人是养得起的上限；
- **蒙骗成本**：注入记忆、维持认知滤网是服务器负载，几千个「人格」是分布式阵列的合理承载量级；
- **驾驶员数量＝可用无人机数量**：每个驾驶员退出虚拟空间后接入一台无人机躯体，而 A 站资源紧张，能维持的无人机就是几百台——这是「驾驶员群体数量受控制」最硬的解释，正好补上那个待定项；
- **「极少数」觉醒者**：几百驾驶员中约 1% 量级即个位数到十几人，与「极少数」吻合；
- **独裁的具体性**：三千到五千人的小镇，配给、复活手续、宵禁能直接落到每个人头上，压迫感才是「具体的」，而不是抽象的政令。

## 四、战争规模

| 维度 | 建议 |
|---|---|
| 主战力量 | **战机级飞行器上万架**（环带全域保有量，中小型为主，含民用飞行器/船征用武装化） |
| 运输机（带内摆渡） | **数千架**（战前是环带物资流转的血管；大战中武装化为兵力投送/补给骨干，战后大量幸存） |
| 舰船（远洋级） | **数千艘**（战前是运输与战略命脉；大战中大量损耗） |
| 兵员 | 数十万（云上人/人类），大部分用于操纵飞行器与维护体系 |
| 性质 | 要地争夺 + 航道切断的中等规模内战 |
| 持续时间 | 3–6 年，各地结束时间不同 |

### 战线平面化（带状结构的战争后果）

环带的扁平带状结构会把**战线拉扯到黄道面附近的一个平面上**——战争由此**近似现实中的二维战争**（海战/陆战），设计时可以套用现实战争经验，不必再过多考虑空间的三维结构：

- **带内**＝沿海/陆地作战：战机级飞行器利用小行星遮蔽打游击、争夺要地，是战争主力；
- **带外**＝深海海战：舰船在平面两侧的开阔空间机动，负责补给线、远洋切入与战略机动。

这解释了残骸为何「遍布环带」——带内平面上布满战机级残骸，海量且密集；舰船残骸则是罕见的**大件**，在战后打捞中价值最高。

### 飞行器与舰船的层级

- **战机级飞行器**：环带内活动的主力，也是环带社会的主要行动工具，如同现代社会的汽车保有量——采矿、运输、客运、巡逻、护航都靠小型飞船维持日常运转，保有量天然在**万级**；环带大战征用并武装化了这批飞行器，成为战场主力；
- **运输机（带内摆渡，介于战机与舰船之间的中型飞行器）**：带内跨弧区运输的主要载体，保有量在**千级**——战前承担站间与弧区间的客货运，是环带物资流转的血管；大战中大规模武装化，成为两军的「兵力投送/补给运输」骨干，也是战后最稀缺的幸存物资之一；
- **舰船（中大型、远洋级）**：数量少得多（**数千艘**），专司带外深海航行——出带、内缘直线航行的补给与远航能力是它的立身之本；**但在环带内部，中大型飞船反而没有优势**：体积大、转向笨重、被小行星遮蔽地形束缚，还消耗不成比例的补给，带内交战不是它的主场。战时舰船被拉进平面战线沦为消耗品——**这正是「巨企N损失惨重」「矩阵联合战后无力远征」的物理根源**：远洋舰队的覆灭无法在战后重建。

### 与 A 站的量级区分

万级飞行器、千级舰船是**全环带保有量**的尺度；A 站是战后衰败、被孤立打残的单站，连战机级都难以大量维持：

- **无人机（战机级作业单位）**：**数百台**（见人口规模「驾驶员数量＝可用无人机数量」），即驾驶员躯体；
- **运输机（带内摆渡）**：**十至数十架**（建议 **20–50 架**），每架搭载 5–10 架无人机。A 站无远洋舰船。

两者不矛盾——A 站是环带万机池中的一员残兵。

## 五、经济规模

- **紧平衡**：打捞回收量 ≈ 站内日消耗，几乎无盈余。虚拟社会没有肉体维生需求，实际消耗集中在**电力（反应堆+太阳能）、服务器散热、载具燃料、无人机生产原料**——这正好解释了大灾变后维生系统失效与虚拟社会照常运转如何并存（维生系统与电力系统是两套独立体系）。
- **矿业联盟注资＝生命线**：正因为紧平衡，注资才不可或缺，白手套关系才有分量。
- 数值锚点建议定为「日回收 ≈ 日耗」，单个驾驶员每次出勤恰好覆盖自身成本并略有盈余，具体数字留待资源系统词条细化。

## 六、汇总与互锁校验

| 维度 | 推荐规模 |
|---|---|
| 时间 | 大灾变距今约 20 年；虚拟社会运行约 5–8 年 |
| 空间 | 故事区段 0.2–0.5 AU；带内（沿海，战机级）日常打捞半径千公里级；带外（深海，舰船级）长途 |
| 人口 | 虚拟社会 3000–5000；驾驶员 200–500；学社 30–80 |
| 战争 | 战机级飞行器**万架级** + 运输机**数千架级** + 远洋舰船**数千艘级**；持续 3–6 年 |
| 经济 | 打捞 ≈ 消耗的紧平衡 |

这套规模是**互锁**的：资源紧张 → 养不起大社会 → 几千人的小镇 → 只能维持几百台无人机与十至数十架运输机 → 驾驶员几百人 → 觉醒者个位数。任意一个数字变动都会牵动其他数字，建议作为一组整体敲定。

比绝对值更重要的是**比例关系**：居民 : 驾驶员 : 学社 : 逃难者 ≈ 20 : 1 : 0.2 : 0.5。若后续觉得五千人偏大或偏小，可整体缩放。

**工具保有量与人口规模脱钩**：飞行器/舰船数量是「工具保有量」而非「人口规模」的函数——环带人口稀疏但工具密集（人均拥有多艘中小型飞行器，类似现实中矿业经济重装备、轻人力的形态）。因此环带人口只有千万级以下，飞行器却达万级、舰船数千级，三者不成比例，互不矛盾。
