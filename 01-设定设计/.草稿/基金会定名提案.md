# 基金会／教会定名方案

> **状态：** 设计方案（2026-08-14）——在否决「千化」、评估「团结会／团结社／聚灵会」之后，给出可落地的定名。  
> **采用方案：** **共信会（The Fiducia）**（若要与学社严格「社」对仗，可改为 **共信社**）  
> **对照：** 学社（The Collegium）＝中文短名 + 正式拉丁／英文名；本组织对齐同一规格。

---

## 一、设计目标

组织要同时像三样东西，却只宜有一个主名：

1. **光明会式互助会**——结社、共济、可加入  
2. **基金会／银行门脸**——信贷、担保、铭牌不违和  
3. **有教义的秘社**——能通向位相／归一／堆人格，但不在店招上写「造神」

前几轮候选的缺口：

| 名称 | 缺口 |
|------|------|
| 教会 | 只剩宗教面 |
| 千化＊ | 方向反了（一→多） |
| 团结会 | 互助会对，辨识空、无教义钩 |
| 聚灵会 | 钩子强，民俗／修仙腔，银行门脸打架 |
| 位相社 | 教义准，日常互助会语感弱 |

需要的是：**一个字里就拧住「金融信用」和「宗教信仰」**，再用「共／会」补上互助会骨架。

---

## 二、采用方案：共信会（The Fiducia）

### 定名表

| 层级 | 名称 | 使用场合 |
|------|------|----------|
| **正式中文定名** | **共信会** | 设定文档、组织自称、任务、对白正式称呼 |
| **正式英文定名** | **The Fiducia** | 站外文书、铭牌、双语场合（对仗 The Collegium） |
| **基金会对外名** | **共信基金会**／Fiducia Foundation | 银行、信贷、担保、储蓄 |
| **口语／场所** | **教会** | 仅指宗教场所或居民随口指称；**非正式定名** |
| **旧称** | 千化教会 | 历史用名／误名，不再作现行官名 |

### 为什么合适

| 字 | 作用 |
|----|------|
| **共** | 共同、共济——多→一的互助方向；比「团结」少口号腔 |
| **信** | **双关**：信用（金融、共同基金、担保）＋信仰（宗教面）——一个字同时服务银行与布道 |
| **会** | 光明会式结社后缀；不是「教会」 |

| 维度 | 表现 |
|------|------|
| 主张方向 | 「共」＝往一处收；不与归一打架 |
| 起源叙事 | 灾后**共同信用**互助 → 宗教化后「共信」自然长出信仰义 |
| 基金会门脸 | 「共信会／共信基金会」可上铭牌，像正经金融机构 |
| 互助会气质 | 短、可喊、可加入；与学社并列为站内两大结社 |
| 教义空间 | 名字不剧透造神；位相／归一／堆人格留给《位相圣典》与剧情 |
| 与学社对仗 | 学社＝技术标准权威；共信会＝信用／信仰权威 |

### 明线一句话（驾驶员可懂）

> 共信会是站上那家又放贷又布道的互助会——大家把信用绑在一起，也把信绑在一起。

### 暗线不写进店招（创作侧掌握）

共同信用制度扩张之后，「信」被教义读成：众人皆为可归并的位相／碎片；堆人格是「共信」的极端工程读法。名字允许这层读法，但不强迫明线听出。

### 与学社对照

| | 学社 | 共信会 |
|--|------|--------|
| 中文 | 学社 | 共信会 |
| 英文 | The Collegium | The Fiducia |
| 气质 | 学阀互助会 | 信用—信仰互助会 |
| 明线本职 | 运维技术、标准权威 | 信贷救援、布道、基金会 |
| 名称钩子 | 「学」＝技术／标准 | 「信」＝信用／信仰双关 |

### 英文取名说明

- **Fiducia**：罗马法「信托／信任」；金融上有 fiduciary（受托）血统，和基金会、担保同源。  
- 不用 Solidarity（工会腔）、Spirit Assembly（过教会）、Myriad（千化旧义）。  
- 与 Collegium 同属短拉丁名，站外文书并列干净。

## 三、备选与已评名称

### 团结社（本次）

与「团结会」同词根，只把后缀换成「社」——为了和「学社」字面对仗。

| 维度 | 相对团结会 | 相对共信会 |
|------|------------|------------|
| 与学社对仗 | **更好**（学社／团结社） | 共信会是「会」，对仗略松，但仍可并列 |
| 互助会语感 | 仍强；「社」比「会」略偏结社／学会 | 共信会仍更像光明会式「会」 |
| 辨识／教义钩 | **无改善**——团结仍空 | 仍弱于「信」双关 |
| 口号腔 | **仍在**——团结＋社，仍易像社团标语 | 共信更少标语感 |
| 基金会门脸 | 可用 | 共信基金会更贴信贷本业 |

**结论：** 比「团结会」更适合和学社并置，但**不能靠换后缀补上教义与信用钩子**；仍不替代「共信会」作主名。若你特别在意「两社对仗」，可把共信会改成 **共信社**（见下），而不是退回团结社。

### 若坚持「社」后缀：共信社

与学社严格对仗时，主方案可微调为：

| | 学社 | 共信社 |
|--|------|--------|
| 中文 | 学社 | 共信社 |
| 英文 | The Collegium | The Fiducia |

语义仍靠「共信」，只改后缀；**推荐度与共信会几乎同等**，按你想要「会」还是「社」择一即可。

### 其他已评（摘要）

| 名称 | 结论 |
|------|------|
| 千化＊ | 否决——方向反 |
| 团结会 | 不单用——空泛；对仗弱于团结社 |
| 团结社 | 不单用——对仗好，钩子仍空 |
| 聚灵会 | 不单用——钩子强，玄学腔／银行门脸差 |
| 位相社／完形会 | 备选锋利名，见上节 |

## 四、文案与呈现约定

1. 正式文书、任务名、UI 势力标签：写 **共信会**。  
2. 银行柜面、贷款合同：写 **共信基金会**（可括号注共信会）。  
3. NPC 指宗教场所：可说「去教会」「教会那栋」——口语，不改官名。  
4. 深入线／布道：出现《位相圣典》、归一、位相人格；不必改会名。  
5. 全库替换时机：本方案确认后，再改 `教会.md` 文件名与交叉引用。

---

## 五、前序否决摘要（备查）

| 名称 | 结论 |
|------|------|
| 千化 | 否决——字义一→多，与归一主张相反 |
| 团结会 | 不单用——互助会对，空泛 |
| 团结社 | 不单用——与学社对仗更好，钩子仍空；若要「社」后缀优先改共信社 |
| 聚灵会 | 不单用——钩子强，民俗／修仙腔与银行门脸冲突；至多作派别外号 |
| 教会 | 降为口语 |

---

## 六、决议草案

1. 官方定名采用 **共信会（The Fiducia）**。  
2. 基金会对外名采用 **共信基金会（Fiducia Foundation）**。  
3. 「教会」仅作口语／场所称呼。  
4. 废止「千化」作为现行定名词根。  
5. 组织性质不变：基金会形态；横跨金融、技术、宗教；暗线仍为独立外部势力与堆人格事业。  
6. 确认后：重命名明线／暗线词条并全库替换正式称呼。
