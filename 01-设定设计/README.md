# 设定设计

世界观与创意设计文档。面向叙事、美术、程序。

## 文档职责（单一权威源）

| 层级 | 文件 | 职责 |
|------|------|------|
| 总览 | `00-总览/*总览与导读.md` | 世界观分层总览 + **故事规模** + 导航；一句话摘要置于顶部，连贯叙述以正文为准 |
| 正文 | `*/明线·正文.md` `*/暗线·正文.md` | 连贯骨架叙述，细节链到词条 |
| 词条 | `01-明线/` `02-暗线/` 各目录 | **细节权威源** |
| 时间线 | `*·时间线.md` | 事件序，不复述正文 |
| 对照 | `明暗对照表.md` | 「以为 X / 实际 Y」检索 |
| 待定 | `待定项汇总.md` | **全局待定唯一索引**；词条可保留本地 `- [ ]` |

写作明线内容只引 `01-明线`；设计暗线/反转引 `02-暗线`；查矛盾用对照表。
