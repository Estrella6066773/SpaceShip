## 时段概览

- 大灾变后环带失联，矩阵联合近地派武装接管政权；矩阵联合对环带要地武装接管，矿主抵抗并组成矿业联盟（见 [矩阵联合（战时）](势力/矩阵联合.md)、[矿业联盟](势力/矿业联盟.md)）。
- 双方角力演变为环带内战，即环带大战（见 [环带大战](事件/环带大战.md)）。
- 巨企N（矩阵联合体系内）在战争中损失惨重，统治地位滑落（见 [巨企N（战后背景）](../03-战后/势力/巨企N.md)）。
- 战争期间空间站维生系统失效、无法修复，站上人们走投无路，用不合标准的思维上传技术将思维上传至云端，沦为非法人工智能——这批逃难者后来建立了自由政府（见 [思维上传与逃难](事件/思维上传与逃难.md)、[自由政府](../03-战后/势力/自由政府.md)）。
