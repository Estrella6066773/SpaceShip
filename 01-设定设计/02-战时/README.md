## 时段概览

- 大灾变后环带失联，矩阵联合近地派武装接管政权；矩阵联合对环带要地武装接管，矿主抵抗并组成矿业联盟（见 [矩阵联合（战时）](势力/矩阵联合.md)、[矿业联盟](势力/矿业联盟.md)）。
- 双方角力演变为环带内战，即环带大战——战争在**各地持续**，仅 A 站所在区域战斗在空间站被破坏后不久结束，世界其他地区仍战乱（见 [环带大战](事件/环带大战.md)、草稿主文档·决议二十七）。
- 巨企N（矩阵联合体系内）在战争中损失惨重，但**战后仍是大势力**，仍控制相当规模的管辖区（见 [巨企N（战后背景）](../03-战后/势力/巨企N.md)、草稿主文档·决议三十）。
- 战争中 A 站被**部分破坏**（维生链断裂、补给耗尽），因战争与巨企N**被动脱离**、失去补给渠道；脱离后站上人们在**战后绝境**中用不合标准的思维上传技术上传思维，沦为非法人工智能——这批逃难者后来建立了自由政府（见 [思维上传与逃难](事件/思维上传与逃难.md)、[空间站](../01-战前/概念/空间站.md)、[自由政府](../03-战后/势力/自由政府.md)、草稿主文档·决议二十三、决议二十六、决议二十七）。
- 战争中后期，交战双方投放由人工智能操控、抹去身份标识的**离散AI**战争兵器（见 [离散AI](概念/离散AI.md)、草稿主文档·决议二十九）。
