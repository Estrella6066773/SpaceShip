## 时段概览

- 环带即法厄同环，位于火星与木星之间，是两地往来必经的中转地带（见 [环带](概念/环带.md)）。
- 矩阵联合是大灾变前的太阳系性政权，云城网络在太阳系内扩张，法厄同环是其前沿布点地带（见 [矩阵联合（前史）](势力/矩阵联合.md)）。
- 大灾变破坏稳定航道，环带与近地轨道、马尔斯轨道失联，原有商业模式瓦解（见 [大灾变](事件/大灾变.md)）。
- 空间站坐落在环带之上，是矩阵联合体系内的巨企（即**巨企N**）**曾经的合作方**（并非其资产，且曾依附于巨企N）（见 [空间站](概念/空间站.md)、[巨企N（战后背景）](../战后/势力/巨企N.md)、草稿主文档·决议十七、决议十八）。
